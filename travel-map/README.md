# 여행 숙소 지도 (travel-map)

구글 시트에 호텔 목록만 적으면 지도가 저절로 바뀌는 여행 지도예요.
동네 영역(빨간 점선), 명소(★), 번호 호텔 마커가 지도에 표시되고, 호텔을 누르면 사진·평점·장단점·예약 버튼이 담긴 상세 카드가 열려요.

- 주소(배포 후): `https://linuscompany.co.kr/travel-map/`
- 특정 시트를 바로 보기: `.../travel-map/?sheet=시트CSV주소`

---

## 1. 파일 구성

| 파일 | 하는 일 | 리노님이 고치나요? |
|---|---|---|
| `config.js` | 제목, 구글 시트 주소, 제휴 안내 문구 | ✅ 여기만 고치면 돼요 |
| `data/sample.csv` | 예시 데이터 (후쿠오카). 구글 시트 템플릿으로도 써요 | 템플릿으로만 사용 |
| `index.html` · `style.css` · `app.js` | 화면과 동작 | ❌ 안 고쳐도 돼요 |
| `vendor/leaflet/` | 지도 라이브러리 (무료, BSD 라이선스) | ❌ |

---

## 2. 구글 시트 연결하기 (5분)

1. **템플릿 가져오기**: 구글 시트 새로 만들기 → `파일 > 가져오기 > 업로드`에서 `data/sample.csv` 선택 → "현재 시트 바꾸기"
2. **내용 고치기**: 호텔 이름, 좌표, 평점, 내 제휴 링크를 채워요 (아래 3번 표 참고)
3. **웹에 게시**: `파일 > 공유 > 웹에 게시` → 시트 선택 → 형식을 **쉼표로 구분된 값(.csv)** 으로 → 게시 → 나온 주소 복사
4. **주소 붙여넣기**: `config.js`의 `sheetCsvUrl: ''` 따옴표 안에 붙여넣기

이제 시트만 고치면 지도가 바뀌어요. 구글이 게시본을 갱신하는 데 **최대 5분쯤** 걸릴 수 있어요. 지도 오른쪽 위 **↻ 버튼**을 누르면 다시 불러와요.

> 💡 시트 '편집' 주소(`.../edit#gid=0`)를 붙여넣어도 돼요. 이때는 시트 공유를 **"링크가 있는 모든 사용자: 뷰어"** 로 해 두세요.

---

## 3. 시트 칸 설명

첫 줄 제목은 그대로 두세요. 줄마다 **구분** 칸에 `동네` / `명소` / `호텔` 중 하나를 적어요.

| 칸 | 동네 줄 | 명소 줄 | 호텔 줄 | 예시 |
|---|---|---|---|---|
| 구분 | 동네 | 명소 | 호텔 | 호텔 |
| 동네 | 탭 이름 | 속한 동네 | 속한 동네 | 하카타역 |
| 번호 | | | 지도에 보일 번호 | 1 |
| 이름 | 동네 이름 | 명소 이름 | 호텔 이름 | 미야코 호텔 하카타 |
| 위도 / 경도 | | ✅ | ✅ | 33.5902 / 130.4232 |
| 평점 / 후기수 | | | 선택 | 9.2 / 12513 |
| 역까지 | | | 선택 | 하카타역 3분 |
| 가격 | | | 선택 (비우면 "날짜마다 달라요") | ₩180,000 |
| 사진 | | | 사진 주소 (https) | |
| 아고다 / 트립닷컴 | | | **내 제휴 링크** | https://... |
| 한줄소개 / 장점 / 아쉬운점 | 동네 설명 | | 카드에 표시 | |
| 체크인 / 체크아웃 | | | 선택 | 15:00 / 11:00 |
| 영역좌표 | 빨간 점선 영역 | | | 아래 참고 |

**좌표 구하는 법**: 구글맵에서 장소를 마우스 오른쪽 클릭하면 맨 위에 `33.5902, 130.4232` 같은 숫자가 나와요. 클릭하면 복사돼요. 앞 숫자가 위도, 뒤 숫자가 경도예요.

**영역좌표 만드는 법** (둘 중 편한 것):
- 점을 `위도,경도; 위도,경도; ...` 형식으로 3개 이상 적기
- [geojson.io](https://geojson.io)에서 다각형을 그리고, 오른쪽 코드에서 `"coordinates": [[[...]]]` 부분의 대괄호 덩어리를 통째로 복사해 붙여넣기

**아고다·트립닷컴 칸이 비어 있으면** 부킹닷컴 검색 버튼이 대신 나와요. `config.js`에 `bookingAid`(부킹닷컴 제휴 ID)를 적으면 그 버튼도 제휴 링크가 돼요.

## 4. 꼭 알아둘 점

- **예시 데이터**: `sample.csv`의 좌표는 대략적인 위치이고, 사진은 실제 호텔 사진이 아닌 무료 예시 사진(Unsplash)이에요. 평점은 블로그 글 기준이라 바뀔 수 있어요. 지도를 공개하기 전에 직접 확인한 정보로 바꿔 주세요. 예시 데이터일 때는 화면에 "예시 데이터"·"예시 사진" 표시가 떠요.
- **사진 저작권**: 호텔 공식 사진이나 다른 블로그 사진은 허락 없이 쓰지 마세요. 직접 찍은 사진이나 제휴사가 제공하는 이미지를 쓰세요.
- **제휴 표시**: 제휴 링크가 하나라도 있으면 목록 아래에 `config.js`의 안내 문구가 자동으로 표시돼요. 공정위 '경제적 이해관계' 표시용이에요.
- **지도 사용량**: 배경 지도는 무료 OpenStreetMap이에요. 방문자가 아주 많아지면(하루 수만 명) Mapbox 같은 유료 지도로 바꾸는 게 좋아요.
- **블로그에 넣기**: 네이버 블로그는 지도를 직접 넣을 수 없어요. 글에 링크나 지도 캡처 이미지를 넣고, 누르면 이 지도 페이지로 오게 하세요. 티스토리·워드프레스는 `<iframe src="https://linuscompany.co.kr/travel-map/" width="100%" height="700">` 으로 넣을 수 있어요.

## 5. 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭하면 브라우저가 파일을 못 읽어요(보안 제한). 이 폴더에서 아래 명령을 실행하고 `http://localhost:8000` 에 접속하세요.

```bash
python3 -m http.server 8000
```
