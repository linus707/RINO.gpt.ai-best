# 여행 숙소 지도 (travel-map)

구글 시트에 호텔 목록만 적으면 지도가 저절로 바뀌는 여행 지도예요.
동네 영역(빨간 점선), 명소(★), 번호 호텔 마커가 지도에 표시되고, 호텔을 누르면 사진·평점·장단점·예약 버튼이 담긴 상세 카드가 열려요.

맨 위 검색창 하나로 세 가지 검색이 돼요.

| 검색 | 이렇게 쳐요 | 결과 | 준비물 |
|---|---|---|---|
| ① 내 추천 호텔 | `대욕장`, `나카스`, `미야코` | 시트 속 호텔 중 맞는 곳만 빨간 번호로 표시 | 없음 |
| ② 장소 + 주변 호텔 | `캐널시티`, `교토역`, `오사카 난바` | 그 장소로 이동하고 주변 숙소를 회색 점으로 표시. 지도를 옮기면 **🔍 이 지역 호텔 찾기** 버튼 | 없음 (무료) |
| ③ 아고다 실시간 가격 | 날짜·인원 고르고 **가격 보기** | 사진·평점·오늘 가격·할인율 목록, 누르면 아고다 제휴 링크로 예약 | 아고다 제휴 API 키 + 워커 (아래 6번) |

오른쪽 위 **🗺️ 지도 / 🏆 순위** 버튼으로 순위 화면으로 바꿀 수 있어요. 주소 끝에 `#ranking`을 붙이면 처음부터 순위 화면이 열려요. 블로그 글에 링크로 걸기 좋아요.

**순위 화면 기능**
- 정렬: 종합 / 구글 평점 / 아고다 평점 / 후기 많은 순
- 평점 조건: 아고다 평점·후기 수, 구글 평점·후기 수를 최소~최대로 걸러요
- 필터: 동네 탭, 5성급, 시트의 `태그`로 자동 생성되는 #태그 (예: #대욕장)
- 날짜·인원: "2주 뒤 1박", "이번 주말" 빠른 선택. **가격 보기**를 누르면 아고다 제휴 링크(partnersearch.aspx 형식)에 날짜와 인원이 들어가요
- 숙소마다 유형·성급·동네, 영문 이름, 태그, 역까지 걸리는 시간, 구글·아고다 평점과 후기 수, 종합 점수, 후기 요약(위치·교통 / 객실 / 서비스 / 아쉬운 점 / 이런 분께 추천), 가격 비교 버튼(아고다·트립닷컴·라쿠텐), 지도에서 보기, 자세히
- 점수 계산법을 화면 아래에 공개해요. 후기가 적은 곳은 평균 쪽으로 당겨서, 후기 몇 개뿐인 곳이 1등이 되지 않아요

검색어가 내 추천 호텔에 있으면 ①을 보여주고, 없으면 ②로 장소를 찾아요. ③은 켜 두면 함께 새로고침돼요.

- 주소(배포 후): `https://linuscompany.co.kr/travel-map/`
- 특정 시트를 바로 보기: `.../travel-map/?sheet=시트CSV주소`

## 1. 파일 구성

| 파일 | 하는 일 | 리노님이 고치나요? |
|---|---|---|
| `config.js` | 제목, 구글 시트 주소, 실시간 가격 설정, 제휴 안내 문구 | ✅ 여기만 고치면 돼요 |
| `data/sample.csv` | 예시 데이터 (후쿠오카). 구글 시트 템플릿으로도 써요 | 템플릿으로만 사용 |
| `index.html` · `style.css` · `app.js` | 화면과 동작 | ❌ 안 고쳐도 돼요 |
| `vendor/leaflet/` | 지도 라이브러리 (무료, BSD 라이선스) | ❌ |
| `worker/` | ③ 실시간 가격용 Cloudflare 워커 (사이트에는 안 올라가요) | 키만 넣어요 |

## 2. 구글 시트 연결하기 (5분)

1. **템플릿 가져오기**: 구글 시트 새로 만들기 → `파일 > 가져오기 > 업로드`에서 `data/sample.csv` 선택 → "현재 시트 바꾸기"
2. **내용 고치기**: 호텔 이름, 좌표, 평점, 내 제휴 링크를 채워요 (아래 3번 표 참고)
3. **웹에 게시**: `파일 > 공유 > 웹에 게시` → 시트 선택 → 형식을 **쉼표로 구분된 값(.csv)** 으로 → 게시 → 나온 주소 복사
4. **주소 붙여넣기**: `config.js`의 `sheetCsvUrl: ''` 따옴표 안에 붙여넣기

이제 시트만 고치면 지도가 바뀌어요. 구글이 게시본을 갱신하는 데 **최대 5분쯤** 걸릴 수 있어요. 지도 오른쪽 위 **↻ 버튼**을 누르면 다시 불러와요.

> 💡 시트 '편집' 주소(`.../edit#gid=0`)를 붙여넣어도 돼요. 이때는 시트 공유를 **"링크가 있는 모든 사용자: 뷰어"** 로 해 두세요.

## 3. 시트 칸 설명

첫 줄 제목은 그대로 두세요. 줄마다 **구분** 칸에 `제목` / `동네` / `명소` / `호텔` 중 하나를 적어요. 비워 둬도 되는 칸은 비워 두세요.

- **`제목` 줄 (선택, 한 줄)**: `이름` 칸 = 지도 제목, `한줄소개` 칸 = 부제목. 비우면 `config.js`의 제목을 써요.
- **도시마다 시트를 따로** 만들면 편해요. 주소 뒤에 `?sheet=시트CSV주소`를 붙이면 그 도시 지도가 열려요. 예: 로마 시트 링크, 방콕 시트 링크를 블로그 글마다 따로 걸기.

| 칸 | 어디에 쓰여요 | 예시 |
|---|---|---|
| 구분 / 동네 / 이름 | 줄 종류, 속한 동네(탭), 이름 | 호텔 / 하카타역 / 미야코 호텔 하카타 |
| 번호 | 지도에 보이는 번호 | 1 |
| 영문이름 / 유형 / 성급 | 순위 카드 (유형: 호텔·료칸·리조트·호스텔) | Miyako Hotel Hakata / 호텔 / 4 |
| 태그 | 쉼표로 여러 개. #태그 필터가 자동으로 생겨요 | 대욕장, 옥상수영장 |
| 위도 / 경도 | 지도 위치 (명소·호텔은 꼭 필요) | 33.5902 / 130.4232 |
| 아고다평점 / 아고다후기수 | 10점 만점 | 9.2 / 12513 |
| 구글평점 / 구글후기수 | 5점 만점. 비우면 "구글 정보 없음" | 4.4 / 3210 |
| 역까지 | 가까운 역과 도보 시간 | 하카타역 3분 |
| 가격 | 선택 (비우면 "가격은 매일 달라요") | ₩180,000 |
| 사진 | 사진 주소 (https) | |
| 아고다 / 트립닷컴 / 라쿠텐 | **내 제휴 링크** | https://... |
| 구글맵 / 상세링크 | 구글맵 장소 주소, 내 블로그 후기 글 주소 | |
| 한줄소개 / 장점 / 아쉬운점 | 카드 문구 (동네 줄은 동네 설명) | |
| 요약후기수 / 위치교통 / 객실 / 서비스 / 추천대상 | 후기 요약. 요약후기수는 "후기 N개를 읽고 정리" 표시용 | 120 / 역 3분… |
| 체크인 / 체크아웃 | 시간 | 15:00 / 11:00 |
| 영역좌표 | 동네 줄의 빨간 점선 영역 | 아래 참고 |

> 예전 시트의 `평점`·`후기수` 칸은 아고다 평점·후기 수로 그대로 읽어요.

**평점은 직접 확인해서 적어 주세요.** 구글·아고다 페이지를 자동으로 긁어오는 건 각 회사 약관 위반이에요. 나중에 아고다 제휴 API가 열리면 아고다 평점과 후기 수는 자동으로 받을 수 있어요.

**좌표 구하는 법**: 구글맵에서 장소를 마우스 오른쪽 클릭하면 맨 위에 `33.5902, 130.4232` 같은 숫자가 나와요. 클릭하면 복사돼요. 앞 숫자가 위도, 뒤 숫자가 경도예요.

**영역좌표 만드는 법** (둘 중 편한 것):
- 점을 `위도,경도; 위도,경도; ...` 형식으로 3개 이상 적기
- [geojson.io](https://geojson.io)에서 다각형을 그리고, 오른쪽 코드에서 `"coordinates": [[[...]]]` 부분의 대괄호 덩어리를 통째로 복사해 붙여넣기

**아고다·트립닷컴 칸이 비어 있으면** 부킹닷컴 검색 버튼이 대신 나와요. `config.js`에 `bookingAid`(부킹닷컴 제휴 ID)를 적으면 그 버튼도 제휴 링크가 돼요.

## 4. 꼭 알아둘 점

- **예시 데이터**: `sample.csv`의 좌표는 대략적인 위치이고, 구글 평점은 확인하지 못해 비워 뒀어요(그래서 "구글 정보 없음"으로 보여요). 사진은 실제 호텔 사진이 아닌 무료 예시 사진(Unsplash)이에요. 평점은 블로그 글 기준이라 바뀔 수 있어요. 지도를 공개하기 전에 직접 확인한 정보로 바꿔 주세요. 예시 데이터일 때는 화면에 "예시 데이터"·"예시 사진" 표시가 떠요.
- **사진 저작권**: 호텔 공식 사진이나 다른 블로그 사진은 허락 없이 쓰지 마세요. 직접 찍은 사진이나 제휴사가 제공하는 이미지를 쓰세요.
- **제휴 표시**: 제휴 링크가 하나라도 있으면 목록 아래에 `config.js`의 안내 문구가 자동으로 표시돼요. 공정위 '경제적 이해관계' 표시용이에요.
- **지도 사용량**: 배경 지도는 무료 OpenStreetMap이에요. 방문자가 아주 많아지면(하루 수만 명) Mapbox 같은 유료 지도로 바꾸는 게 좋아요.
- **블로그에 넣기**: 네이버 블로그는 지도를 직접 넣을 수 없어요. 글에 링크나 지도 캡처 이미지를 넣고, 누르면 이 지도 페이지로 오게 하세요. 티스토리·워드프레스는 `<iframe src="https://linuscompany.co.kr/travel-map/" width="100%" height="700">` 으로 넣을 수 있어요.

## 5. 검색 기능이 쓰는 무료 서비스

- **장소 검색**: OpenStreetMap Nominatim. 검색 버튼을 누를 때만, 1초에 1번까지만 요청해요(자동완성은 정책상 금지라 넣지 않았어요).
  - 지도에 있는 도시 근처를 먼저 찾아요. 예: 뉴욕 지도에서 "타임스 스퀘어" → 홍콩 쇼핑몰이 아니라 뉴욕.
  - **외국 장소는 한글 이름이 없는 곳이 많아요.** "카오산로드"는 못 찾고 "Khao San Road"는 찾아요. 못 찾으면 화면에 영어로 검색해 보라는 안내가 떠요.
- **주변 호텔**: OpenStreetMap Overpass. 지도를 일정 수준 이상 확대했을 때만 찾아요. 서버가 바쁘면 잠시 뒤 다시 누르면 돼요.
- 주변 호텔은 누구나 고칠 수 있는 지도 데이터라 **평점·가격·사진이 없고**, 빠진 숙소도 있어요. 그래서 카드에 "직접 확인하지 않은 숙소" 안내가 붙어요. 추천 호텔과 60m 안에 겹치는 곳은 자동으로 빼요.
- 방문자가 아주 많아지면(하루 수천 번 이상 검색) 유료 장소 검색 서비스로 바꾸는 걸 권해요.

## 6. ③ 아고다 실시간 가격 켜기

아고다 API 키는 브라우저에 넣으면 누구나 훔쳐 갈 수 있어요. 그래서 **Cloudflare 워커**(무료 작은 서버)가 키를 숨기고 대신 아고다에 물어봐요. 코드는 `worker/` 폴더에 있어요.

1. **아고다 제휴 가입**: [partners.agoda.com](https://partners.agoda.com)에서 가입하고 승인받기 → 담당자에게 "Affiliate Lite API(Long Tail Search)" 사용을 요청 → **사이트 ID**와 **API 키** 받기
2. **워커 올리기**: 컴퓨터에 Node.js를 설치하고 `travel-map/worker` 폴더에서 실행
   ```bash
   npx wrangler login
   ```
   ```bash
   npx wrangler secret put AGODA_SITE_ID
   ```
   ```bash
   npx wrangler secret put AGODA_API_KEY
   ```
   ```bash
   npx wrangler deploy
   ```
   마지막 명령이 `https://travel-hotel-api.○○○.workers.dev` 같은 주소를 알려줘요.
3. **config.js 채우기**: `hotelApiUrl`에 워커 주소, `agodaCityId`에 도시 ID(숫자)를 적어요. 아고다 사이트에서 도시를 검색하면 주소창의 `city=숫자`가 도시 ID예요. 여러 도시를 쓰면 `agodaCities: { '후쿠오카': 숫자, '오사카': 숫자 }`처럼 적어요.
4. 내 사이트 주소가 `linuscompany.co.kr`이 아니면 `worker/wrangler.toml`의 `ALLOWED_ORIGINS`를 바꿔요. 여기 없는 사이트는 워커가 막아요.

**알아둘 점**
- 아고다 응답에는 좌표가 없어서 실시간 결과는 지도 핀이 아니라 **목록**으로 보여요.
- 같은 조건은 워커가 10분 동안 저장해 두고 재사용해서 아고다 호출이 줄어요.
- 워커는 진짜 아고다 대신 가짜 서버로만 테스트했어요(`node tests/travel-hotel-api.mjs`). 키를 받으면 실제로 한 번 확인해 주세요. 아고다 담당자가 다른 API 주소를 알려주면 `wrangler.toml`의 `[vars]`에 `AGODA_ENDPOINT = "주소"`를 추가하세요.

## 7. 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭하면 브라우저가 파일을 못 읽어요(보안 제한). 이 폴더에서 아래 명령을 실행하고 `http://localhost:8000` 에 접속하세요.

```bash
python3 -m http.server 8000
```
