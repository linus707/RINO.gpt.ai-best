# 04. 초보자 설치 가이드

## 시작 전 체크 (5분)

| 항목 | 권장 | 확인 방법 |
|---|---|---|
| 운영체제 | macOS / Linux / Windows(WSL2 권장) | - |
| 메모리 | 최소 8GB, 쾌적하게는 16GB | 설정 > 시스템 정보 |
| 디스크 | 여유 10GB 이상 (모델이 수 GB) | - |
| 인터넷 | 설치와 모델 다운로드 때만 필요 | - |

## 방법 A. 가장 쉬운 길 (추천)

공식 한 줄 설치 스크립트가 uv, 파이썬 환경, Ollama, 시작 모델까지 한 번에 설치해요. (약 3분)

**macOS / Linux / WSL2**
```bash
curl -fsSL https://open-jarvis.github.io/OpenJarvis/install.sh | bash
```

**Windows (PowerShell)**
```powershell
irm https://open-jarvis.github.io/OpenJarvis/install.ps1 | iex
```

> 인터넷에서 받은 스크립트를 바로 실행하는 방식이에요. 불안하면 주소를 브라우저로 먼저 열어 내용을 읽어본 뒤 실행하세요.

설치가 끝나면:
```bash
jarvis doctor     # 상태 점검 (문제 있으면 여기서 알려줘요)
jarvis            # 대화 시작
```

## 방법 B. 데스크톱 앱 (명령어가 싫다면)
[최신 릴리스](https://github.com/open-jarvis/OpenJarvis/releases/latest)에서 `.exe` / `.dmg` / `.deb` / `.AppImage`를 받아 설치하면 돼요.

## 방법 C. 소스로 설치 (이 레포 스크립트)
```bash
cd RINO.gpt.ai-best
bash openjarvis/scripts/setup.sh
```
원본을 `../OpenJarvis`에 clone하고 `uv sync`로 설치한 뒤, 내 설정 파일을 복사해요.

## 첫 실행 따라하기

```bash
# 1. 설정 적용 (처음엔 가벼운 대화용)
cp openjarvis/configs/rino-chat.toml ~/.openjarvis/config.toml

# 2. 모델 준비
ollama pull qwen3.5:4b

# 3. 질문해 보기
jarvis ask "여행 블로그 제목 아이디어 5개 알려줘"

# 4. 브라우저 화면으로 쓰기 (Node.js 22+ 필요)
jarvis gui
```

익숙해지면 `rino-research.toml` → `rino-monitor.toml` 순서로 바꾸세요.

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| `jarvis: command not found` | 가상환경을 켜세요: `source .venv/bin/activate` 또는 앞에 `uv run` 붙이기 |
| `No module named 'openjarvis_rust'` | `jarvis memory index`는 Rust 확장이 필요해요. 방법 A로 설치하면 자동, 소스 설치 시 `uv run maturin develop -m rust/crates/openjarvis-python/Cargo.toml` |
| 답변이 너무 느림 | 더 작은 모델(`qwen3.5:4b`)로 바꾸기 |
| 답변 품질이 낮음 | `qwen3.5:9b`로 올리거나, 중요한 글은 Claude로 다듬기 |
| Ollama 연결 실패 | `ollama serve` 실행 여부 확인 |

3. API 키는 레포에 커밋하지 말고 환경변수로만 쓰세요.
