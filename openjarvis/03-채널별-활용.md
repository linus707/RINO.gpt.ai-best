# 03. 리노 채널별 활용 시나리오

모든 시나리오는 **"AI가 초안·정리, 리노가 최종 판단"** 구조예요. 완전 자동 게시는 품질과 계정 안전 면에서 권하지 않아요.

## 공통 흐름

```
수집(뉴스·트렌드·내 자료) → 정리(요약·아이디어) → 초안 → 리노 검수 → 게시
        └── OpenJarvis 담당 ──────────────┘         └ 리노/Claude ┘
```

## 1) 세계여행 블로그

| 작업 | 에이전트 | 예시 명령 |
|---|---|---|
| 여행지 자료조사 | `deep_research` | `jarvis ask --agent deep_research "리스본 3박4일 동선과 비수기 날씨 정리"` |
| 내 여행 기록 검색 | 메모리 검색 | `jarvis memory index ./travel` 후 `jarvis ask "지난 일본 여행 때 간 카페 목록"` |
| 글 뼈대 만들기 | `simple` | `jarvis ask "리스본 여행 블로그 목차를 H2 5개로"` |

팁: `travel-climate.py` 같은 기존 스크립트 결과를 색인하면 "언제 가는 게 좋은지" 글감이 빨리 나와요.

## 2) 가구 전문 브랜드 (Linus Company)

| 작업 | 방법 |
|---|---|
| 문의 답변 초안 | 가격 JSON과 제품 설명을 색인 → "A 의자 가격과 배송 안내 답변 초안" |
| 제품 소개 글/캐러셀 문구 | 콘텐츠 플랜의 수요일 "제품 한 개 깊게 보기"에 맞춰 문구 3안 생성 |
| 경쟁·트렌드 점검 | `scheduled-monitor`로 매주 월요일 "이사·신혼 가구 트렌드 키워드" 요약 |

주의: 가격·재고 같은 **사실 정보는 반드시 내 자료 기준**으로 답하게 하고, 발송 전 직접 확인하세요.

## 3) 스트릿포토

| 작업 | 방법 |
|---|---|
| 사진 한 줄 이야기 | 촬영 메모를 입력해 캡션 3안 |
| 해시태그 정리 | 지난 게시물 태그를 색인해 일관된 태그 세트 추천 |
| 주간 회고 | 금요일 게시물 모음을 일요일 블로그 글로 재활용 (콘텐츠 플랜 구조와 동일) |

## 자동 예약 예시 (`rino-monitor.toml` 사용)

```bash
jarvis scheduler start

# 평일 오전 9시 - 오늘의 콘텐츠 아이디어
jarvis scheduler create \
  --prompt "docs/content-plan 기준으로 오늘 올릴 콘텐츠의 훅 3개와 캡션 초안을 정리해줘" \
  --schedule "0 9 * * 1-5" \
  --agent operative \
  --tools "knowledge_search,memory_store,think"

# 매주 월요일 오전 8시 - 트렌드 점검
jarvis scheduler create \
  --prompt "이사/신혼 가구 관련 이번 주 트렌드 키워드 5개를 근거와 함께 요약해줘" \
  --schedule "0 8 * * 1" \
  --agent operative \
  --tools "web_search,memory_store,think"
```

## 수익화 연결 (경제적 자유 로드맵 관점)

| 단계 | 목표 | OpenJarvis 역할 |
|---|---|---|
| 1단계 | 콘텐츠 제작 시간 절반으로 | 자료조사·초안·캡션 자동화 |
| 2단계 | 꾸준한 발행 | 예약 실행으로 아이디어가 매일 준비됨 |
| 3단계 | 문의 → 판매 전환 | 문의 응답 초안, FAQ 정리 |
| 4단계 | 시스템화 | 스킬로 저장해 반복 작업 템플릿화 |

먼저 1단계만 2주 써보고, 시간이 실제로 줄었는지 확인한 뒤 넓히세요.
