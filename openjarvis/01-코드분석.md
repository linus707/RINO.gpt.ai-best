# 01. OpenJarvis 코드 분석

## 한 줄 요약
**내 PC에서 돌아가는 AI 비서를 만드는 프레임워크.** 클라우드 API 대신 로컬 모델(Ollama 등)을 기본으로 쓰고, 필요할 때만 클라우드를 불러요.

## 5가지 핵심 부품 (공식 아키텍처)

| 부품 | 역할 | 쉬운 비유 |
|---|---|---|
| Intelligence | 어떤 모델을 쓸지 정의 | 직원 이력서 |
| Engine | 모델을 실제로 돌리는 엔진 (Ollama, vLLM, llama.cpp, 클라우드) | 직원이 일하는 사무실 |
| Agents | 작업 방식 (대화, 도구 사용, 반복 실행) | 직원의 업무 스타일 |
| Memory / Tools | 문서 저장·검색, 웹검색, 파일·코드 실행 | 서류함과 도구함 |
| Learning | 쌓인 기록(trace)으로 개선 | 업무 일지로 실력 향상 |

## 폴더 지도 (`src/openjarvis/`)

| 폴더 | 내용 |
|---|---|
| `agents/` | 에이전트 구현 (simple, orchestrator, deep_research, morning_digest, operative 등) |
| `engine/` | 모델 실행 백엔드 |
| `tools/` | 웹검색, 파일 읽기/쓰기, 코드 실행, 브라우저, PDF, 날씨, 지식 검색 등 |
| `connectors/` | 외부 서비스 연결: Gmail, Google Drive/캘린더, Notion, Obsidian, Slack, GitHub, 뉴스 RSS, Hacker News 등 |
| `channels/` | 메신저 연결: Telegram, Discord, Slack, 이메일, Twilio SMS, webhook 등 |
| `memory/` | 문서 색인과 검색 (SQLite 기본) |
| `scheduler/` | 크론 방식 예약 실행 |
| `skills/` | 스킬 설치·관리 (agentskills.io 표준) |
| `cli/` | `jarvis` 명령어들 |
| `server/` | OpenAI 호환 API 서버 (`jarvis serve`) |
| `security/`, `sandbox/` | 권한 제어, Docker 격리 실행 |
| `rust/`, `frontend/`, `desktop/` | Rust 확장, 웹 UI, 데스크톱 앱 |

## 에이전트 종류

| 에이전트 | 실행 방식 | 용도 |
|---|---|---|
| `simple` | 즉시 | 단순 대화 |
| `orchestrator` | 즉시 | 도구를 골라 쓰는 다단계 추론 |
| `native_react` | 즉시 | 생각 → 행동 → 관찰 반복 |
| `native_openhands` | 즉시 | 파이썬 코드를 만들어 실행 |
| `deep_research` | 즉시 | 출처 달린 다단계 리서치 |
| `morning_digest` | 스케줄 | 매일 아침 브리핑 (음성 포함) |
| `operative` | 지속 | 실행 간 상태를 기억하는 자율 에이전트 |
| `monitor_operative` | 지속 | 장기 모니터링 |

## 설정 구조 (`~/.openjarvis/config.toml`)

```toml
[engine]        # 어떤 엔진 (ollama 등)
[intelligence]  # 어떤 모델, 온도
[agent]         # 기본 에이전트, 최대 턴 수
[tools]         # 허용할 도구 목록
[tools.storage] # 저장소 (sqlite)
[server]        # API 서버 주소·포트
```

## 주요 명령어

```bash
jarvis                 # 대화 시작
jarvis ask "질문"      # 한 번 질문
jarvis gui             # 브라우저 UI
jarvis init --preset <이름> --force   # 프리셋 적용
jarvis memory index <폴더>            # 문서 색인
jarvis scheduler start / create       # 예약 작업
jarvis connect gdrive                 # Gmail·캘린더 연결
jarvis skill install hermes:<이름>    # 스킬 설치
jarvis doctor                         # 상태 점검
```

## 리노 관점의 장단점

**장점**: 로컬 실행이라 API 비용이 거의 0원에 가깝고, 내 사진·글 같은 자료가 밖으로 나가지 않아요. 예약 실행과 메신저 연동이 있어서 "자동 시스템"을 만들기 좋아요.

**단점**: 로컬 모델은 클라우드 모델(Claude 등)보다 글 품질이 낮을 수 있어요. 컴퓨터 사양(메모리, GPU)이 받쳐줘야 하고, 설치 구성(Rust 확장 등)이 초보에게는 다소 복잡해요. 그래서 **글 초안과 자료 정리는 OpenJarvis, 최종 다듬기는 Claude**처럼 역할을 나누는 걸 추천해요.
