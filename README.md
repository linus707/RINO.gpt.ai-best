# RINO.gpt.ai-best

## 소개

이 프로젝트는 인공지능(AI) 기반의 다양한 기능을 활용하여 사용자에게 효율적인 정보 제공과 작업 자동화를 지원하는 도구입니다.

프로젝트의 목적은 AI 기술을 활용하여 반복 작업을 줄이고, 더 빠르고 정확한 결과를 제공하는 것입니다.

## 주요 기능

* AI 기반 텍스트 생성 및 응답
* 사용자 요청에 따른 정보 분석 및 요약
* 자동화된 데이터 처리 기능
* 확장 가능한 모듈 구조

## 사용 방법

1. 저장소를 다운로드하거나 클론합니다.

   ```bash
   git clone https://github.com/사용자명/RINO.gpt.ai-best.git
   ```

2. 프로젝트 폴더로 이동합니다.

   ```bash
   cd RINO.gpt.ai-best
   ```

3. 필요한 패키지를 설치합니다.

   ```bash
   npm install
   ```

4. 프로젝트를 실행합니다.

   ```bash
   npm start
   ```

## 미수금 푸시 알림
- `scripts/due-notify.mjs`가 `.github/workflows/push.yml`(5분마다)에서 함께 실행돼요. 동기화 Gist의 장부에서 잔금이 남은 주문 중 예정일이 지났거나 3일 이내인 건을 찾아, 정해 둔 시각(기본 한국 시간 9시) 뒤 첫 실행 때 하루 한 번 관리자 기기로 웹 푸시를 보내요.
- 기본 알림에는 건수와 잔금 합계만 담고, 고객 이름은 앱 설정(장부 > 결제·회계 > 미수금 푸시 알림)에서 켠 경우에만 넣어요. 필요한 비밀값은 기존 푸시와 같아요(`SYNC_GIST_TOKEN`, `SYNC_GIST_ID`, `VAPID_PRIVATE_KEY`).
- 알림을 누르면 `/?ledger=pay`로 열려 장부의 결제·회계 탭이 보여요.

## 일본어 회화
- `japanese.html`: 리노 전용 일본어 회화 연습 앱이에요(`/japanese.html`). 홈·AI 회화·상황별 코스·발음 쉐도잉·단어장·마이페이지(학습 리포트) 6개 화면이고, 휴대폰 홈 화면에 추가하면 따로 앱처럼 열려요(`japanese.webmanifest`).
- 코스 6개(카페·편의점·길 묻기·호텔·친구 약속·비즈니스)의 대화와 쉐도잉 문장, 단어 20개는 파일 안 `COURSES`·`VOCAB`에 들어 있어요. 문장을 추가하려면 거기에 원문·가나 읽기·뜻을 넣으면 한글 발음은 자동으로 만들어져요.
- 듣기·말하기는 브라우저의 음성 합성·음성 인식을 써요. 발음 점수는 "인식된 문장이 목표 문장과 얼마나 같은지"로 계산해요.
- 'AI 자유 회화'만 Anthropic API 키가 필요해요(마이페이지 → 설정). 키와 학습 기록은 그 기기의 브라우저에만 저장돼요.

## 보안 방화벽
사이트는 두 겹으로 지켜요.
- **페이지 방화벽(콘텐츠 보안 정책)**: 모든 페이지(`index.html`·`pos.html`·`price.html`·`translate.html`·`japanese.html`·`offline.html`) 맨 위 `Content-Security-Policy`에 적힌 주소로만 연결·불러오기가 돼요. 누군가 악성 코드를 끼워 넣어도 다른 서버에서 스크립트를 불러오거나 허용되지 않은 서버로 자료를 보내는 길이 막혀요. 다른 사이트가 우리 화면을 몰래 끼워 넣는 것(클릭재킹)도 막아요.
- **서버 방화벽(워커)**: 로그인·푸시·일정 서버로 오는 모든 요청을 먼저 걸러요. 자세한 규칙은 `worker/README.md`의 '방화벽'을 보세요.
- **새 외부 서비스를 붙일 때**: 그 페이지의 `connect-src`(연결), 글꼴·스타일이면 `font-src`·`style-src`에 주소를 추가해야 해요. 빠뜨리면 그 기능만 동작하지 않고, 메인 앱은 "보안 방화벽이 … 연결을 막았어요" 안내를 띄워요.
- 로그인 서버(워커)는 `*.workers.dev` 주소면 그대로 되고, 자체 도메인이면 배포할 때 `scripts/inject-auth.mjs`가 허용 목록에 자동으로 넣어요. Notion 연동 워커를 자체 도메인에 따로 둔다면 `index.html`의 `connect-src`에 직접 추가해 주세요.
- 한계: 앱이 한 파일 안의 인라인 스크립트로 되어 있어 `script-src`에 `'unsafe-inline'`이 들어가 있어요. 페이지 안에 직접 끼워진 스크립트의 실행 자체는 막지 못하므로, 화면에 넣는 값은 지금처럼 꼭 `esc()`를 거쳐야 해요.

## 매장 POS 새 테마 (삼성닷컴식)
- `/pos-samsung.html`: 기존 매장 POS(`/pos.html`)와 기능은 똑같고 겉모습만 바꾼 화면이에요. 흰 바탕·검정 글자, 검정 알약 버튼, 고른 칸만 파란 링으로 표시해요. 기존 `pos.html`은 그대로예요.
- 모양은 `pos-samsung.css` 한 파일에서만 고쳐요. 배포할 때 `scripts/build-pos-theme.mjs`가 `pos.html`에 이 파일을 입혀 `pos-samsung.html`을 자동으로 만들어요(그래서 POS 기능을 고치면 두 화면에 함께 반영돼요).
- 내 컴퓨터에서 미리 보려면 `node scripts/build-pos-theme.mjs`를 실행한 뒤 생긴 `pos-samsung.html`을 열어요. 이 파일은 자동 생성물이라 저장소에는 올리지 않아요(`.gitignore`).

## 매트리스 구매 화면
- `buy.html`: 매트리스 한 모델을 크게 보여 주고 규격·수량·결제 방식을 고르는 화면이에요(`/buy.html`, 특정 모델은 `/buy.html?m=HT-R 26NEW`). 왼쪽은 제품 그림, 오른쪽은 옵션과 주문 요약이에요.
- 가격은 `prices.json`의 '매트(35)(MA)' 분류에서 읽어, 이름 끝의 규격(SS·DD·LQ…)으로 모델을 묶어요. 가격표를 바꾸면 이 화면도 같이 바뀌어요.
- 결제는 받지 않아요. '견적 복사하기'를 누르면 고른 내용이 글로 복사돼요. 월 금액은 합계를 개월 수로 나눈 단순 계산이고 할인·배송비·이자는 넣지 않았어요.
- 제품 그림은 예시 그림 한 장이에요(규격이 커지면 폭만 넓어져요). 실제 제품 사진은 아직 없어요.
