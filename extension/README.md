# Linus Company 크롬 확장 프로그램

데스크톱 크롬에서 Linus Company 워크스페이스를 바로 열고, AMS의 제품 표를 앱 단가표로 보내요.

## 설치 (개발자 모드, 1분)
1. 이 `extension` 폴더를 내 컴퓨터에 둬요. (GitHub에서 저장소를 ZIP으로 받아 압축을 풀면 `extension` 폴더가 있어요)
2. 크롬 주소창에 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더를 선택해요.
4. 퍼즐 아이콘에서 Linus Company를 **고정**하면 툴바에 보여요.

## 쓰는 법
- **앱 창으로 열기**: 주소창 없는 작은 창으로 앱을 열어요. 일반 탭과 같은 저장 공간을 써서 로그인·데이터가 그대로예요.
- **AMS 표를 단가표로**
  1. 평소처럼 AMS에 로그인해서 제품을 검색해요. (확장 프로그램은 로그인하거나 검색하지 않아요)
  2. 표가 보이면 화면 오른쪽 아래에 **📋 단가표에 담기** 버튼이 생겨요. 누르면 지금 화면의 표가 담겨요.
  3. 페이지를 넘기거나 다른 모델을 검색해 또 담아도 돼요(같은 코드는 한 번만).
  4. 툴바 아이콘 → **앱 단가표로 보내기**. 앱의 가져오기 창에 미리 채워지니 미리보기를 확인하고 **가져오기**를 눌러요.
  - 「엑셀 변환」 화면의 글(CSV/TAB)도 같은 버튼으로 담겨요.

## 안전
- 권한: 저장소(`storage`)와 `linuscompany.co.kr`, `ams.acebed.co.kr` 두 사이트만.
- AMS 아이디·비밀번호는 읽거나 저장하지 않아요. 버튼을 눌렀을 때 화면에 보이는 제품 표만 담아요.
- 앱은 받은 표를 바로 저장하지 않고 가져오기 창에 보여 줘요. 관리자 로그인이 필요해요.
