# 에이스침대 정림동점 — 네이버 블로그 포스팅 스킬

실제 발행 글 분석으로 검증된 개선 패턴을 기반으로, D.I.A+ 최적화 블로그를 자동 작성하는 스킬이다.
얼뚱트립(여행) 블로그와는 완전히 분리된 브랜드이므로 절대 혼용하지 않는다.

| **브랜드명** | 에이스침대 정림동점 |
| **퍼스널 브랜드** | 수면큐레이터 리노 |
| **핵심 포지션** | 침대를 파는 곳이 아니라, 수면의 질을 처방하는 곳 |
| **운영지역** | 대전 서구 (정림동·관저동·도안지구·도마동) / 세종 / 충청권 |
| **브랜드 컬러** | 골드 #C9A96E · 차콜 #2C2C2A |

### 고정 매장 정보 (모든 포스팅 하단 필수)
```
📍 대전 서구 정림동 495번지 (계백로 1262)
📞 042-585-9963 (방문 전 연락 주시면 더 여유롭게 상담 가능)

- HT-V, DT3 — 고급형

> ⚠️ 리노님의 이전 직업(의료/병원) 관련 언급은 절대 금지.

## 2단계: 제목 공식

로컬 키워드 + 문제 상황 + 해결 약속 조합. `[에이스침대 정림동점]` 브래킷은 제목 앞 또는 뒤에 배치.

**공식 A — 로컬 + 시즌형** (지역 검색 선점)
```
대전 [지역명] [시즌 이슈] [주제] — [핵심 질문]? [에이스침대 정림동점]
```
> 예: 대전 서구 도안지구 이사 준비 체크리스트 — 침대 교체 타이밍은?

**공식 B — 문제 경고형** (후킹 강도 최고)
```
[주제] — 놓치면 [구체적 손해]까지 옵니다
```
> 예: 장마철 매트리스 습기·진드기 관리법 — 놓치면 알레르기까지 옵니다

**공식 C — 비교/판단형** (구매 전환)
```
[A] vs [B], [타겟]이라면 정답은 이겁니다
```

**공식 D — 상담 경험형** (D.I.A+ 경험 신호)
```
수면큐레이터가 상담하며 가장 많이 [듣는/보는] [주제] TOP N
```

## 3단계: 본문 구조 (7블록 황금 공식)

### BLOCK 1 — 고정 인사 문구 (필수, 한 글자도 변경 금지)
```
하루 8시간, 당신의 수면을 과학으로 처방합니다.
에이스침대 정림동점 수면큐레이터 리노입니다. 🛏️
```

### BLOCK 2 — 후킹 문구 (❝ ❞ 이탤릭 3줄, 필수)
```
❝ [1줄: 공감·문제 상황 제시]
[2줄: 상담 경험 기반 신뢰 강조]
[3줄: "5분만 투자하면 ___가 정리됩니다" 클릭 유도] ❞
```

### BLOCK 3 — 실제 상담 에피소드 (D.I.A+ 경험 신호 핵심)
- "저도 처음엔 그렇게 생각했는데요", "실제로 상담을 해보면" 등 실경험 표현
- 고객의 착각 → 전문가 관점 전환 서사가 가장 효과적
- 1~3문단, 짧고 구체적으로

### BLOCK 4 — 본문 (이모지 소제목 + 체크리스트)
- 소제목: `🌧️ [소제목]` 또는 `✅ [소제목]` 형식
- **문단은 3~5줄로 짧게** (모바일 완독률 = 체류시간 = 랭킹 신호)
- 핵심 수치·키워드는 **굵게**
- **체크리스트는 반드시 본문에 노출** — 접기/펴기 절대 금지 (검증된 실패 패턴)
- 체크리스트 항목은 5~6개, 어미는 "~했다/않았다" 과거형 통일
- "N개 이상 해당되면 ___" 판단 기준 문장 필수
- 사진 자리: `[📸 사진: 설명]` 형식으로 표시

### BLOCK 5 — 침실별/타겟별 추천 (제품 연결)
```
👫 부부 침실 → [기능 근거] → 추천: HT-VII · 로얄에이스 90s
👴 부모님 방 → 체압분산+적당한 경도 → 추천: DT3 (+ 방문 체압 테스트 권장 문구)
👧 아이 방 → 척추 정렬 지지 경도 → 추천: CA2 또는 AT
```
> **"전문 상담 필요"로만 끝내지 않는다** — 최소 1개 제품은 반드시 명시 (검증된 실패 패턴)

### BLOCK 6 — 리노's Pick 마무리
```
### 리노's Pick

[핵심 요약 한 문장 — "결국 핵심은 ___ 세 가지로 정리됩니다"]
[매장 방문/교체 고려 자연 연결 2~3줄]

💬 [키워드 지정형 댓글 CTA]
```

### BLOCK 7 — 함께 보면 좋은 글 (내부 링크 2~3개)
- **앵커 텍스트는 매번 다르게 변형** — "[에이스침대 정림동점] ..." 동일 패턴 반복 금지 (검증된 실패 패턴)
- 예: "매트리스 교체 시기, 이렇게 판단하세요", "이사 전 침대 교체, 왜 타이밍이 전부인가"

## 4단계: D.I.A+ 최적화 필수 규칙 (검증된 실패 패턴 기반)

이번 실제 발행 글 분석에서 확인된 문제를 방지하는 규칙. **예외 없이 적용한다.**

### 🚫 금지 사항
1. **접기/펴기에 핵심 콘텐츠 숨기기 금지** — 체크리스트·판단 기준은 반드시 본문 노출
2. **뉴스·나무위키 등 타 매체 이미지 캡처 인용 금지** — 저작권 위험. 자체 인포그래픽 또는 텍스트로 대체
3. **출처 없는 수치 단정 금지** — 입주 세대 수 등은 웹 검색 검증 후 사용하거나 "변동 가능, 최신 공고 확인 권장" 톤으로 완화
4. **막연한 CTA 금지** — "궁금한 점 댓글로" 단독 사용 금지
5. **CA(클럽에이스) 언급 금지**, 이전 직업 언급 금지
6. **이중 부정·비문 금지** — 발행 전 오탈자 검수 필수

### ✅ 필수 포함 (콘텐츠 성과 3대 규칙)
1. **📌 저장할 이유 1개 이상** — "이 체크리스트, 저장해두고 ___할 때 바로 확인하세요"
2. **❤️ 감성 + 실용 결합** — 상담 에피소드(감성) + 수치·체크리스트(실용)
3. **💬 키워드 지정형 댓글 CTA** — "댓글에 '습도' 남겨주세요, 상황 맞춰 답변드릴게요"

## 발행 전 최종 체크리스트

```
□ 고정 인사 문구 원문 그대로 포함

□ 매장 정보(주소·전화·운영시간) 포함
□ 오탈자·비문 전체 검수 완료
