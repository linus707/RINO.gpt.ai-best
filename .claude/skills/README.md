# 마케팅·브랜딩 스킬 (ECC에서 가져옴)

이 폴더의 스킬은 Claude Code가 **이 레포를 열면 자동으로 인식**해요.
대화 중에 "브랜드 톤 잡아줘", "블로그 글 써줘"처럼 말하면 알맞은 스킬이 켜져요.
`/brand-voice`처럼 이름으로 직접 불러도 돼요.

- 출처: [affaan-m/ECC](https://github.com/affaan-m/ECC) v2.2.3 (커밋 `3f14a10`)
- 라이선스: MIT → [ECC-LICENSE](ECC-LICENSE)
- 원본 그대로 복사했어요. 업데이트할 때 같은 폴더를 덮어쓰면 돼요.

| 스킬 | 한 줄 설명 | 리노 채널 활용 |
|---|---|---|
| `brand-discovery` | 8단계 인터뷰로 브랜드북 만들기 | 가구 브랜드 정체성 정리 |
| `brand-voice` | 실제 글에서 말투 프로필 추출 | 리노만의 말투를 모든 글에 통일 |
| `article-writing` | 긴 글(블로그·가이드) 작성 | 세계여행 블로그 포스팅 |
| `content-engine` | 한 소스를 여러 플랫폼용으로 변환 | 블로그 1편 → 인스타·쇼츠·스레드 |
| `seo` | 검색 노출 점검·키워드 설계 | 블로그·가구 상세페이지 검색 노출 |
| `market-research` | 출처 있는 시장·경쟁 조사 | 가구 경쟁 브랜드 분석 |
| `marketing-campaign` | 런칭 캠페인 전체 설계 | 신제품·이벤트 캠페인 |

자세한 사용법은 [docs/ecc-marketing-guide.md](../../docs/ecc-marketing-guide.md)를 보세요.

> 참고: 이 폴더는 웹사이트 배포(`pages.yml`)에 포함되지 않아요.
