# phone-harness (이 저장소용 규칙)

`phone-harness`는 에이전트가 실제 폰을 탭·스크롤·입력·읽기 할 수 있게 해 주는 외부 도구예요.
배경과 설치 방법은 `docs/phone-harness.md`에 있어요.

## 시작 전

1. `command -v phone-harness`로 설치 여부를 확인해요. 없으면 설치하지 말고 `docs/phone-harness.md`의 설치 방법을 안내해요.
2. 폰은 사용자의 컴퓨터에 연결돼 있어요. 클라우드 세션(원격 컨테이너)에서는 책상 위 폰에 닿지 않으니, 그 경우 사용자 컴퓨터에서 실행해야 한다고 알려요.
3. 전체 사용법은 `phone-harness skill` 출력에 있어요. 폰을 조작하기 전에 한 번 읽어요.

## 꼭 지킬 것

- **사용 기록 전송 끄기**: 모든 호출 앞에 `DO_NOT_TRACK=1`을 붙이거나 `scripts/phone/run.sh`로 실행해요. 기본 설정에서는 스크립트 전문, `type_text`에 넣은 글자, 화면 출력이 외부 통계 서버로 나가요.
- **밖으로 나가거나 되돌리기 어려운 동작은 먼저 물어봐요**: 보내기, 게시, 팔로우, 좋아요, 결제, 삭제, 설정 변경.
- **PIN·비밀번호·인증번호는 절대 입력하지 않아요.** 사용자가 직접 입력하게 해요.
- **비밀값을 스크립트에 넣지 않아요.** 직원 계정, 토큰, 고객 정보(장부·POS 화면에 보이는 이름과 금액)를 출력하거나 저장하지 않아요.
- **인스타그램·블로그 자동 활동은 하지 않아요**(자동 좋아요·팔로우·댓글·대량 게시). 계정 제재 위험이 있어요. 초안 준비까지만 하고 게시는 사용자가 직접 눌러요.

## 이 저장소에서 쓰는 곳

- 실기기 사이트 점검: `scripts/phone/run.sh scripts/phone/site-check.py`
  - 5개 페이지를 폰 브라우저로 열어 첫 화면 글자가 보이는지 확인해요. 읽기 전용이에요.
- 새 스크립트는 `scripts/phone/`에 두고, 맨 위에 `# task: 한 줄 설명`을 적어요.
