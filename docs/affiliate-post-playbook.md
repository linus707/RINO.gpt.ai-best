# 얼뚱트립 제휴마케팅 글 플레이북 (티켓·입장권형)

> 참고 글: 네이버 블로그 「노리의 뚜벅이 여행일기」 — 파리 디즈니랜드 티켓 2종류 비교 (클룩 제휴, 2026.9.5)
> 이 글의 **구조와 설득 방식**만 가져왔어요. 쿠폰 코드·단축 링크·문장·사진은 원작자 것이라 쓰지 않아요.

## 1. 원문이 잘 팔리는 이유 (분석)

| # | 장치 | 원문에서 한 일 | 왜 먹히나 |
|---|---|---|---|
| 1 | **기준일 명시** | "2026년 09월 기준" 첫머리에 적음 | 가격이 변하는 상품이라 신뢰가 생김 |
| 2 | **목차 4개** | 티켓 → DPA(추가상품) → 동선 → 요약 | 검색해서 온 사람이 필요한 곳만 읽음 |
| 3 | **선택지를 표로** | 1파크 vs 2파크, 성인 가격대 | 고민 단계를 한 번에 끝내 줌 |
| 4 | **"왜 여기서 사냐" 3줄** | 늘 더 저렴 / 바우처 간편 / 할부 가능 | 제휴 링크를 누를 이유가 됨 |
| 5 | **공홈 vs 제휴처 실가격 비교** | 같은 날짜, 같은 상품, 차액 표기 (2.7만·4만 원) | 가장 강한 근거. 숫자가 설득함 |
| 6 | **추가 혜택** | 쿠폰, 무료 eSIM | 지금 사야 할 이유 |
| 7 | **업셀 1개** | 기본 티켓 → DPA(패스트트랙) | 객단가 상승. "누구에게 필요한지"를 같이 말함 |
| 8 | **CTA 반복** | 본문 중 3번 "예약하기" 버튼 | 읽다 어디서든 누를 수 있음 |
| 9 | **경험 기반 팁** | 시간별 동선, 어트랙션 순서, 대기 시간 | 제휴 글이지만 정보글로 읽힘 → 체류시간↑ |
| 10 | **요약 체크리스트 + 유형별 추천** | "성인=2파크, 아이 동반=2파크+DPA" | 마지막에 결정까지 해 줌 |
| 11 | **롱테일 태그 14개** | #파리디즈니동선추천 등 | 검색 유입 |

## 2. 원문의 약점 (따라 하지 말 것)

1. **광고 표기가 본문에 없어요.** 제휴 링크와 쿠폰이 있는데 첫머리 표시가 안 보여요. 공정위 추천·보증 심사지침상 "경제적 이해관계"는 **글 맨 앞**에 눈에 띄게 써야 해요.
2. **날짜가 안 맞아요.** 작성일은 9/5인데 "10/3 기준 비교", "연말에 갔는데"가 섞여 있어요. 가격 비교 글은 날짜 하나가 틀리면 신뢰가 무너져요.
3. **"항상 더 저렴" 단정.** 실제로는 날짜·시점마다 달라요. "제가 확인한 날짜 기준"으로 한정해야 안전해요.
4. **쿠폰 코드가 남의 제휴 코드예요.** 내 글에 쓰면 수익도 남에게 가고, 약관·신뢰 문제도 생겨요.

## 3. 얼뚱트립 버전 글 틀 (복사해서 쓰세요)

```
[광고] 이 글에는 제휴 링크가 포함되어 있고, 예약하시면 일정 수수료를 받을 수 있어요.
       (가격은 같아요 / 쿠폰은 제 코드가 아니라 ○○ 기준이에요)

제목: [도시] [상품] 티켓 비교 | 공홈 vs [제휴처] 실제 가격 (○○○○년 ○월 기준)

도입 (3줄)
- 다녀온 날짜 / 누구와 / 이번 글에서 해결할 고민 한 줄
- 가격 기준일: ○○○○.○.○ (변동 상품이라 예약 전 재확인)

목차
1. 티켓 종류와 가격표
2. 어디서 사야 싸요? (실가격 비교)
3. 추가상품 — 필요한 사람 / 안 필요한 사람
4. 현장 동선·팁
5. 요약 체크리스트

1. 가격표   → 표(종류 | 성인 | 아동 | 이런 사람)
2. 비교      → 같은 날짜 캡처 2장 + 차액 한 줄 + 제휴처 장점 3개
   [예약 버튼 ①]
3. 추가상품  → "저는 ○○라서 샀고, ○○이면 필요 없어요"
   [예약 버튼 ②]
4. 동선·팁   → 내가 직접 간 시간표, 대기 시간, 아쉬운 점도 1개
5. 요약      → 체크리스트 5줄 + 유형별 추천
   [예약 버튼 ③]

태그: 롱테일 10~14개 (#도시+상품+가격/할인/동선/꿀팁)
```

### 얼뚱트립에서 꼭 지킬 5가지
1. **광고 표기는 첫 화면 맨 위.** 맨 아래·태그 속에 넣지 않아요.
2. **가격은 내가 확인한 날짜 1개로 통일.** 캡처에 날짜가 보이게 해요.
3. **쿠폰·링크는 내 제휴 계정 것만.** 코드가 없으면 그 칸은 비워 둬요.
4. **단점도 1개 적기.** (예: 대기 4시간, 성수기 가격) → 광고처럼 안 읽혀요.
5. **직접 찍은 사진만.** 공홈·타 블로그 사진은 쓰지 않아요.

## 7. Threads 구성안 (참고: @honol.trip 프로필·글 분석)

### 7-1. 참고 계정이 하는 일

| 장치 | 실제 예 | 배울 점 |
|---|---|---|
| **프로필 4줄** | 닉네임 \| 정체성 / 좌우명 / 다음 여행 일정 / 협업 메일 + 블로그 링크 | 누구인지, 지금 뭐 하는지, 어디로 가면 되는지가 3초 안에 보임 |
| **짧은 줄바꿈 + 말투** | 한 줄 15자 안팎, 반말, 이모지 😳👀 | 스크롤 중에도 읽힘 |
| **진짜 이유 글** | "블로그 쓰는 게 힐링… 매달 들어오는 부수익" | 수익 이야기를 솔직하게 → 신뢰 |
| **타깃 호명 글** | "블로그로 수익이 어려운 사람 있어?" | 누구를 위한 글인지 첫 줄에서 고름 |
| **링크는 다음 글에 따로** | 모집 글 본문엔 문장만, 신청 링크는 바로 아래 글 | 본문 노출을 해치지 않고 링크로 보냄 |
| **반응·후기 인증** | "이런 반응 오면 짜릿" | 사회적 증거 |
| **한 줄 원칙 글** | "쿠폰도 중요하지만 제일 중요한 건 **왜 이 사람 걸 사야 하는지**, 그리고 **상품을 명확히 정해주는 것**" | 제휴 글의 핵심 법칙 (아래 7-2에 반영) |
| **태그 1개** | `#블로그` (Threads는 글당 태그 1개) | 해시태그 남발 안 함 |

### 7-2. 제휴 글에 바로 쓸 법칙 2개 (플레이북 3장에 추가 적용)
1. **할인보다 "왜 내 링크로 사야 하는지"가 먼저예요.** 가격 비교 + 내가 직접 쓴 후기 + 이런 사람에게 맞는다는 이유.
2. **상품을 내가 골라 줘요.** "A도 B도 있어요"가 아니라 "성인은 이거, 아이 동반은 이거"처럼 하나로 정해 주기. (원문 요약 5번의 유형별 추천과 같은 방식)

### 7-5. 제휴 글을 Threads에 올릴 때 (중요)
- **첫 줄에 "[광고]" 또는 "제휴 링크 포함"** 표기. 링크가 답글에 있어도 그 글이 제휴 글이면 표기해요.
- 쿠폰·링크는 **내 제휴 계정 것만** 써요. 참고 계정의 코드·단축 링크는 쓰지 않아요.
- 비교 가격엔 "○월 ○일 확인 기준"을 꼭 붙여요.

### 7-6. 첫 주 글 3개 (얼뚱트립 톤, 복사해서 ○만 채우세요)

톤 규칙: 반말 대신 **"~해요/~했어요"**, 한 줄 15자 안팎, 이모지는 글당 1~2개, 첫 줄에서 결론이나 질문.

**① 월 — 오늘의 한 장 (사진 + 소개)**
```

○○ 골목, 비 오는 저녁

```
→ 링크 없음. 사진은 직접 찍은 것만, 위치 정보(EXIF) 제거 후 올려요.

**② 수 — 제휴 글 (광고 표기 필수)**
```

○○ 입장권, ○월 ○일에 직접 비교했어요

공홈 ○○○원
제휴처 ○○○원
→ ○만 원 차이 (확인일 기준)

저는 ○○이라서 이걸로 골랐어요
○○라면 이쪽이 맞아요

자세한 비교와 링크는 답글에 👇
```
**답글(링크):**
```
비교표·예약 링크: (내 제휴 링크)
가격은 확인일 기준이라 예약 전 한 번 더 봐주세요
```
→ 상품은 하나로 정해서 추천해요. 쿠폰은 내 제휴 계정 것만 써요.

**③ 금 — 질문형 (댓글 유도)**
```
이번 연말 여행지 고민 중이에요

① 오사카

후기 써볼게요 ✈️
```

→ 링크 없음. 댓글에 답해주면 프로필 방문이 늘어요.

## 7-9. 수요일 글 확정본: 오사카 유니버설 스튜디오 재팬(USJ) 티켓

### 먼저 확인된 사실 (2026-11-27 웹 검색 기준, 가격은 직접 확인 필요)
- USJ는 **2026년 7월 1일 판매분부터 스튜디오 패스 가격 방식을 바꿨어요.** 판매가 시작된 뒤에도 날짜별 가격을 조정할 수 있어요. 대신 **이미 산 티켓은 가격이 올라도 추가금이 없어요.** → "일찍 살수록 유리" 가 글의 핵심 각도예요. (출처: USJ 공식 공지, 아래 링크)
- **익스프레스 패스는 스튜디오 패스와 별도 구매**예요. 종류는 4·7·8 등이 있고, 가격은 종류·날짜·재고에 따라 달라요.
- 제3자 사이트의 성인 1일권 범위는 ¥8,400~¥10,900대로 **자료마다 달라요.** 그래서 글에 쓰는 가격은 **내가 직접 같은 날짜로 조회한 값**만 써요.

### 글 쓰기 전, 가격 조회 방법 (10분)
1. 방문 예정일 하나를 정해요 (평일 1개, 주말 1개면 더 좋아요).
2. **USJ 공식 사이트**에서 그 날짜의 스튜디오 패스(성인) 가격을 확인하고 **화면 캡처**해요 (날짜가 보이게).
3. **내 제휴처** 같은 날짜·같은 상품 가격을 확인하고 캡처해요.
4. 익스프레스 패스도 같은 방식으로 하나만(추천 종류) 비교해요.
5. 환율은 그날 기준으로 원화 환산하고 "확인일 ○월 ○일"을 적어요.

> 제휴처 가격이 공식보다 **비싸거나 같으면** "제휴처가 싸다"고 쓰지 마세요. 그때는 "혜택(바우처 즉시 발송·할부·쿠폰)" 중심으로 쓰거나 비교 결과를 그대로 알려요. 숫자가 이기는 글이에요.
