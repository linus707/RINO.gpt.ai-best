# 얼뚱트립 제휴마케팅 글 플레이북 (티켓·입장권형)

> 참고 글: 네이버 블로그 「노리의 뚜벅이 여행일기」 — 파리 디즈니랜드 티켓 2종류 비교 (클룩 제휴, 2026.9.5)
> 이 글의 **구조와 설득 방식**만 가져왔어요. 쿠폰 코드·단축 링크·문장·사진은 원작자 것이라 쓰지 않아요.

---

## 1. 원문이 잘 팔리는 이유 (분석)

| # | 장치 | 원문에서 한 일 | 왜 먹히나 |
|---|---|---|---|
| 1 | **기준일 명시** | "2026년 09월 기준" 첫머리에 적음 | 가격이 변하는 상품이라 신뢰가 생김 |
| 2 | **목차 4개** | 티켓 → DPA(추가상품) → 동선 → 요약 | 검색해서 온 사람이 필요한 곳만 읽음 |
| 3 | **선택지를 표로** | 1파크 vs 2파크, 성인 가격대 | 고민 단계를 한 번에 끝내 줌 |
| 4 | **"왜 여기서 사냐" 3줄** | 늘 더 저렴 / 바우처 간편 / 할부 가능 | 제휴 링크를 누를 이유가 됨 |
| 5 | **공홈 vs 제휴처 실가격 비교** | 같은 날짜, 같은 상품, 차액 표기 (2.7만·4만 원) | 가장 강한 근거. 숫자가 설득함 |
| 6 | **추가 혜택** | 쿠폰, 무료 eSIM | 지금 사야 할 이유 |
| 7 | **업셀 1개** | 기본 티켓 → DPA(패스트트랙) | 객단가 상승. "누구에게 필요한지"를 같이 말함 |
| 8 | **CTA 반복** | 본문 중 3번 "예약하기" 버튼 | 읽다 어디서든 누를 수 있음 |
| 9 | **경험 기반 팁** | 시간별 동선, 어트랙션 순서, 대기 시간 | 제휴 글이지만 정보글로 읽힘 → 체류시간↑ |
| 10 | **요약 체크리스트 + 유형별 추천** | "성인=2파크, 아이 동반=2파크+DPA" | 마지막에 결정까지 해 줌 |
| 11 | **롱테일 태그 14개** | #파리디즈니동선추천 등 | 검색 유입 |

## 2. 원문의 약점 (따라 하지 말 것)

1. **광고 표기가 본문에 없어요.** 제휴 링크와 쿠폰이 있는데 첫머리 표시가 안 보여요. 공정위 추천·보증 심사지침상 "경제적 이해관계"는 **글 맨 앞**에 눈에 띄게 써야 해요.
2. **날짜가 안 맞아요.** 작성일은 9/5인데 "10/3 기준 비교", "연말에 갔는데"가 섞여 있어요. 가격 비교 글은 날짜 하나가 틀리면 신뢰가 무너져요.
3. **"항상 더 저렴" 단정.** 실제로는 날짜·시점마다 달라요. "제가 확인한 날짜 기준"으로 한정해야 안전해요.
4. **쿠폰 코드가 남의 제휴 코드예요.** 내 글에 쓰면 수익도 남에게 가고, 약관·신뢰 문제도 생겨요.

## 3. 얼뚱트립 버전 글 틀 (복사해서 쓰세요)

```
[광고] 이 글에는 제휴 링크가 포함되어 있고, 예약하시면 일정 수수료를 받을 수 있어요.
       (가격은 같아요 / 쿠폰은 제 코드가 아니라 ○○ 기준이에요)

제목: [도시] [상품] 티켓 비교 | 공홈 vs [제휴처] 실제 가격 (○○○○년 ○월 기준)

도입 (3줄)
- 다녀온 날짜 / 누구와 / 이번 글에서 해결할 고민 한 줄
- 가격 기준일: ○○○○.○.○ (변동 상품이라 예약 전 재확인)

목차
1. 티켓 종류와 가격표
2. 어디서 사야 싸요? (실가격 비교)
3. 추가상품 — 필요한 사람 / 안 필요한 사람
4. 현장 동선·팁
5. 요약 체크리스트

1. 가격표   → 표(종류 | 성인 | 아동 | 이런 사람)
2. 비교      → 같은 날짜 캡처 2장 + 차액 한 줄 + 제휴처 장점 3개
   [예약 버튼 ①]
3. 추가상품  → "저는 ○○라서 샀고, ○○이면 필요 없어요"
   [예약 버튼 ②]
4. 동선·팁   → 내가 직접 간 시간표, 대기 시간, 아쉬운 점도 1개
5. 요약      → 체크리스트 5줄 + 유형별 추천
   [예약 버튼 ③]

태그: 롱테일 10~14개 (#도시+상품+가격/할인/동선/꿀팁)
```

### 얼뚱트립에서 꼭 지킬 5가지
1. **광고 표기는 첫 화면 맨 위.** 맨 아래·태그 속에 넣지 않아요.
2. **가격은 내가 확인한 날짜 1개로 통일.** 캡처에 날짜가 보이게 해요.
3. **쿠폰·링크는 내 제휴 계정 것만.** 코드가 없으면 그 칸은 비워 둬요.
4. **단점도 1개 적기.** (예: 대기 4시간, 성수기 가격) → 광고처럼 안 읽혀요.
5. **직접 찍은 사진만.** 공홈·타 블로그 사진은 쓰지 않아요.
