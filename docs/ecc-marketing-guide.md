## 1. 한눈에 보기

이 스킬들은 따로 노는 게 아니라 **하나의 흐름**으로 이어져요.

```
[brand-discovery]  브랜드가 "누구인지" 정하기
        ↓
[brand-voice]      "어떻게 말하는지" 고정하기  ← 모든 글쓰기 스킬이 이 결과를 재사용
        ↓
[market-research]  시장과 경쟁자 파악하기
        ↓
[article-writing]  긴 글(블로그) 만들기
        ↓
[content-engine]   블로그 1편 → 인스타·쇼츠·스레드로 쪼개기
        ↓
[seo]              검색에 걸리게 다듬기
        ↓
[marketing-campaign] 위 전부를 묶어 캠페인으로 실행
```

| 스킬 | 난이도 | 효과 | 리노에게 우선순위 |
|---|---|---|---|
| `brand-voice` | ★☆☆ | 모든 콘텐츠 품질이 올라감 | 🥇 1순위 |
| `content-engine` | ★☆☆ | 콘텐츠 1개 → 여러 개 | 🥇 1순위 |
| `article-writing` | ★☆☆ | 블로그 글 품질 | 🥈 2순위 |
| `seo` | ★★☆ | 블로그 검색 유입 | 🥈 2순위 |
| `brand-discovery` | ★★★ (여러 번 대화) | 가구 브랜드 뼈대 | 🥈 2순위 |
| `market-research` | ★★☆ | 의사결정 근거 | 🥉 3순위 |
| `marketing-campaign` | ★★★ | 런칭 때 한 방 | 🥉 필요할 때 |

## 2. 스킬별 상세 분석

### 🎙️ brand-voice: 리노만의 "말투 지문" 만들기
- **하는 일**: 리노님이 실제로 쓴 글 5~20개를 분석해서 `VOICE PROFILE`(말투 설명서)을 만들어요. 문장 길이, 숫자를 얼마나 쓰는지, 질문을 얼마나 던지는지, **절대 안 쓰는 표현**까지 뽑아내요.
- **좋은 점**: 한 번 만들어 두면 `article-writing`, `content-engine`, `marketing-campaign`이 모두 이 프로필을 그대로 써요. "AI가 쓴 티"가 크게 줄어요.
- **리노 활용**: 반응이 좋았던 블로그 글, 인스타 캡션을 넣어 주세요. 세계여행과 가구 브랜드는 톤이 다르니 **채널별로 하나씩** 만드는 걸 추천해요.
- **말하는 법**: `내 블로그 글 10개야. brand-voice로 말투 프로필 만들어줘`

### 📝 article-writing: 블로그 장문 글쓰기
- **하는 일**: 블로그 글, 가이드, 뉴스레터처럼 긴 글을 써요.
- **핵심 규칙**: ① 구체적인 것(사진, 숫자, 일화)으로 시작해요 ② 설명은 예시 다음에 해요 ③ 형용사 대신 근거를 써요 ④ **사실을 지어내지 않아요**
- **리노 활용**: 여행기를 "파리 여행 꿀팁 10가지"처럼 쓰는 대신 "샤를드골 공항에서 RER 티켓 사다가 30분 날린 이야기"로 시작하는 식이에요. 구조화와 공감을 좋아하는 리노님 스타일과 잘 맞아요.

### ♻️ content-engine: 원소스 멀티유즈
- **하는 일**: 콘텐츠 하나를 플랫폼별 맞춤 콘텐츠로 바꿔요.
- **작동 방식**: 원본에서 핵심 주장 3~7개를 뽑고, 날카로움과 근거 기준으로 순위를 매긴 뒤, **콘텐츠 하나에 아이디어 하나**를 배정해요.
- **리노 활용**: 여행 블로그 1편 → 인스타 캐러셀 1개 + 릴스 대본 1개 + 스레드 3개. 스트릿포토 촬영기 → 사진 설명 캡션 + 촬영 팁 쇼츠.
- **한계**: 기본 설정이 X·LinkedIn·YouTube 기준이에요. 인스타그램과 네이버 블로그는 요청할 때 플랫폼을 꼭 적어 주세요.

### 🔍 seo: 검색 노출 최적화
- **하는 일**: 기술 점검(사이트맵, 로딩 속도 LCP < 2.5초 등), 제목·메타 설명 다듬기, 구조화 데이터(JSON-LD), 키워드와 페이지 연결을 해요.
- **원칙**: 페이지 하나에 검색 의도 하나만 담아요. 꼼수보다 장기적인 품질을 봐요.
- **리노 활용**:
  - 여행 블로그: "도쿄 3박4일 코스" 같은 키워드를 글마다 하나씩 배정
  - 가구 브랜드: 상품 페이지에 `Product`·`Offer` 구조화 데이터 넣기
- **한계**: 구글 기준이에요. 네이버 블로그는 C-Rank·D.I.A. 로직이 달라서 그대로 적용되지 않아요.

### 🧭 brand-discovery: 브랜드북 만들기 인터뷰
- **하는 일**: 8개 모듈(존재 이유 → 포지셔닝 → 타깃 → 성격 → 말투 → 스토리 → 창업자 vs 브랜드 → 최종 브랜드북)을 **질문을 하나씩 던지며** 인터뷰해요.
- **특징**: 답변을 파일로 저장해서 며칠에 걸쳐 이어서 할 수 있어요. "왜 그게 중요하세요?"를 반복해서 핵심 가치까지 파고들어요.
- **리노 활용**: **가구 전문 브랜드**에 가장 잘 맞아요. 7번 모듈 "창업자 브랜드 vs 회사 브랜드"는 퍼스널브랜드 "리노"와 가구 브랜드를 어떻게 나눌지 정하는 데 딱이에요.
- **말하는 법**: `brand-discovery 시작하자. 브랜드 이름은 ○○, 결과는 brand/ 폴더에 저장해줘`

### 📊 market-research: 근거 있는 시장 조사
- **하는 일**: 시장 규모, 경쟁사 비교, 트렌드 조사를 해요. **모든 주장에 출처를 달고**, 사실·추론·추천을 나눠서 정리해요.
- **리노 활용**: 경쟁 가구 브랜드 5곳의 가격대·포지셔닝·약점 분석, 여행 블로그 수익 모델 비교 등.

### 🚀 marketing-campaign: 캠페인 통합 설계
- **하는 일**: 조사 → 포지셔닝 → 제작 → 검수 4단계로 캠페인 전체를 만들어요.
- **결과물**: 포지셔닝 브리프, 랜딩페이지 문구, 이메일 시퀀스, SNS 포스트, 숏폼 대본, 광고 문구 3~4종, 날짜별 콘텐츠 캘린더
- **핵심 규칙**: 포지셔닝이 승인되기 전에는 카피를 한 줄도 쓰지 않아요.
- **리노 활용**: 가구 신제품 출시, 여행 전자책·프리셋 같은 디지털 상품 판매 런칭

## 4. 추천 작업 순서

"AI 기반 자동 수익 시스템" 관점에서는 **한 번 만들어 두면 계속 재사용되는 것**부터 하는 게 이득이에요.

1. **1주차**: `brand-voice`로 채널별 말투 프로필 3개 만들기 → `brand/voice-travel.md` 같은 파일로 저장
2. **2주차**: `content-engine`으로 "블로그 1편 → SNS 3~5개" 루틴 굳히기
3. **3주차**: `seo`로 블로그 키워드 지도 만들기
4. **4주차 이후**: 가구 브랜드에 `brand-discovery`를 여러 세션에 나눠 진행
5. **판매할 상품이 생기면**: `marketing-campaign`

💡 **기존 스킬과 함께 쓰기**: 리노님이 이미 쓰는 `rino-blog-posting`, `rino-content-studio`가 있다면, `brand-voice`로 만든 말투 프로필을 그 스킬에 넣어 주면 효과가 겹치지 않고 더해져요.

## 5. 주의할 점과 한계

- **영어권 기준으로 만들어졌어요.** 금지 표현 목록이 "game-changer", "In today's landscape" 같은 영어예요. 한국어에서는 이렇게 요청하세요: `"여러분 안녕하세요", "~에 대해 알아볼까요?", "꿀팁 대방출" 같은 상투적 표현도 금지해줘`
- **플랫폼 기준이 X·LinkedIn이에요.** 네이버 블로그와 인스타그램은 요청할 때 꼭 적어 주세요.
- **`brand-voice` 안에 ECC 제작자(Affaan)의 기본 말투 설정이 있어요.** 리노님 글을 넣으면 그 설정은 쓰이지 않아요. 샘플 없이 실행하지 마세요.
- **SNS 자동 발행은 포함하지 않았어요.** ECC의 `social-publisher`는 유료 외부 서비스(SocialClaw) API 키가 필요해서 뺐어요. 발행 자동화는 이미 연결된 Metricool이나 Postiz 쪽이 더 맞아요.
- **사실 확인은 꼭 직접 하세요.** 스킬이 "지어내지 말라"고 지시하긴 하지만, 가격·영업시간·법규 같은 정보는 발행 전에 확인하세요.

## 6. PC에 설치하는 방법 (초보자용)

> 이 레포에는 위 7개 스킬이 이미 들어 있어서, **이 레포를 Claude Code로 열면 따로 설치하지 않아도 바로 써요.**
> 아래는 **모든 프로젝트에서** ECC를 쓰고 싶을 때의 방법이에요.

### 방법 A. 필요한 스킬만 골라 설치 ⭐ 추천
가볍고, 기존 스킬과 충돌할 일이 적어요.

**1단계: 준비물 확인.** PowerShell(윈도우) 또는 터미널(맥)을 열고 하나씩 입력하세요. 버전 숫자가 나오면 OK예요.
```bash
node --version
```
```bash
git --version
```
```bash
claude --version
```
- 버전이 안 나오면 먼저 설치하세요: [Node.js](https://nodejs.org) (18 이상, LTS 버전), [Git](https://git-scm.com), Claude Code (2.1 이상)

**2단계: ECC 내려받기**
```bash
git clone https://github.com/affaan-m/ECC.git
```
```bash
cd ECC
```

**3단계: 원하는 스킬만 설치** (맥·리눅스·Git Bash)
```bash
./install.sh --target claude --skills brand-voice,content-engine,article-writing,seo,marketing-campaign,market-research,brand-discovery
```
윈도우 PowerShell에서는 이렇게 입력하세요.
```powershell
.\install.ps1 --target claude --skills brand-voice,content-engine,article-writing,seo,marketing-campaign,market-research,brand-discovery
```

**4단계: 확인.** Claude Code를 새로 열고 `/brand-voice`를 입력해 보세요. 자동완성에 뜨면 성공이에요.

### 방법 B. 플러그인으로 전체 설치
ECC 전체(에이전트, 훅, 명령어 포함)를 쓰고 싶을 때예요. 개발 작업까지 할 거라면 이쪽이에요.

Claude Code 안에서 아래 두 줄을 차례로 입력하세요.
```
/plugin marketplace add https://github.com/affaan-m/ECC
```
```
/plugin install ecc@ecc
```
또는 터미널에서 안내형 설치를 쓸 수도 있어요. 질문이 나오면 **Global user**, **Standard** hooks를 고르세요.
```bash
npx ecc-universal@2.2.3 setup
```
확인은 Claude Code에서 `/plugin list`를 입력해서 `ecc@ecc`가 보이면 끝이에요.

### ⚠️ 꼭 지킬 것
1. **방법 A와 B 중 하나만** 쓰세요. 둘 다 하면 같은 기능이 두 번 실행될 수 있어요.
2. **공식 경로로만** 설치하세요: GitHub `affaan-m/ECC`, npm `ecc-universal`, 플러그인 `ecc@ecc`, 사이트 ecc.tools. 다른 곳의 복사본은 악성코드가 들어 있을 수 있어요.
3. 방법 B는 무거워요. 스킬 327개가 들어와서 Claude가 엉뚱한 스킬을 고를 수도 있어요.

### 지우고 싶을 때
- 방법 B(플러그인): Claude Code에서 `/plugin`을 열고 `ecc@ecc`를 제거하세요.
- npx로 설치했다면 설치했던 폴더에서 아래 명령을 실행하세요. 먼저 `--dry-run`으로 무엇이 지워지는지 확인할 수 있어요.
```bash
npx ecc-universal@2.2.3 uninstall --dry-run
```
```bash
npx ecc-universal@2.2.3 uninstall
```
- 방법 A: `~/.claude/skills/` 폴더에서 해당 스킬 폴더를 지우면 돼요.
