# phone-harness 가이드

AI 에이전트(Claude Code 등)가 **실제 폰을 대신 조작**하게 해 주는 외부 도구예요.
화면의 글자를 읽고, 탭·스크롤·입력을 해요. 폰에는 아무것도 설치하지 않아요.

- 원본: https://github.com/phone-harness/phone-harness (MIT, 0.3.3 알파 단계)
- 이 문서는 2026-11-17 기준 코드(커밋 `4bebff1`)를 직접 읽고 정리했어요.

## 1. 설치 방법

### 먼저 고르기: 내 조합은?

| 내 컴퓨터 | 내 폰 | 가능한 방식 | 난이도 |
| --- | --- | --- | --- |
| 맥 (macOS 15 이상) | 아이폰 (iOS 18 이상) | 아이폰 미러링 | 쉬움 |
| 맥·윈도우·리눅스 | 안드로이드 | USB 또는 Wi-Fi 디버깅 | 보통 |
| 윈도우 | 아이폰 | 내 폰은 불가. 클라우드 폰만 | 유료 |
| 아무거나 | 폰 없음 | 클라우드 폰 | 유료 |

> 윈도우 + 아이폰 조합은 내 아이폰을 직접 조작할 수 없어요. 아이폰 미러링이 맥 전용 기능이라서예요.

### 공통: 프로그램 설치 (컴퓨터에서 한 번)

터미널(맥) 또는 PowerShell(윈도우)에서 실행해요.

1. `uv` 설치 (파이썬 도구 설치기). 맥:

   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

   윈도우:

   ```bash
   winget install astral-sh.uv
   ```

2. phone-harness 설치:

   ```bash
   uv tool install --python 3.12 --upgrade --force phone-harness
   ```

3. **사용 기록 전송 끄기** (꼭 하세요. 이유는 [3번](#3-보안-점검)):

   ```bash
   phone-harness config set telemetry false
   ```

### A. 맥 + 아이폰

1. 맥에서 **아이폰 미러링** 앱을 열고 페어링을 끝내요(폰을 손에 들고 진행).
2. 시스템 설정 > 개인정보 보호 및 보안에서 터미널(또는 Claude Code를 실행하는 앱)에 두 가지를 허용해요.
   - **손쉬운 사용**: 탭과 입력용
   - **화면 기록**: 화면 읽기용. 허용 후 그 앱을 껐다 켜야 적용돼요.
3. 기본 폰을 아이폰으로 정하고 점검해요.

   ```bash
   phone-harness config set platform ios
   ```

   ```bash
   phone-harness doctor ios
   ```

### B. 안드로이드 (맥·윈도우·리눅스)

1. adb 설치. 맥:

   ```bash
   brew install android-platform-tools
   ```

   윈도우:

   ```bash
   winget install Google.PlatformTools
   ```

2. 폰에서 설정 > 휴대전화 정보 > **빌드 번호를 7번** 눌러 개발자 옵션을 켜요.
3. 개발자 옵션 > **USB 디버깅**을 켜고, 케이블로 연결한 뒤 폰에 뜨는 "허용"을 눌러요.
4. 기본 폰을 안드로이드로 정하고 점검해요.

   ```bash
   phone-harness config set platform android
   ```

   ```bash
   phone-harness doctor android
   ```

### C. 클라우드 폰 (폰이 없거나 윈도우 + 아이폰일 때)

| 종류 | 요금 (원본 문서 기준) |
| --- | --- |
| 클라우드 안드로이드 | 분당 5센트. 가입 시 5달러 크레딧(100분) |
| 클라우드 아이폰 | 월 80달러부터 (정액) |

```bash
phone-harness cloud login
```

```bash
phone-harness cloud start
```

```bash
phone-harness cloud stop
```

`cloud start`는 기본 15분 동안 켜져요. 끝나면 `cloud stop`으로 꼭 꺼 주세요(안드로이드는 분당 과금).

### 설치 확인

```bash
phone-harness doctor
```

막힌 단계를 순서대로 알려 줘요. 자주 나오는 것:

| 증상 | 원인과 해결 |
| --- | --- |
| 아이폰 화면이 검게 잡힘 | 화면 기록 허용 후 앱을 재시작하지 않음 |
| 아이폰 탭이 안 먹힘 | 손쉬운 사용 권한 없음 |
| 안드로이드 `unauthorized` | 폰 잠금 해제 후 "USB 디버깅 허용" 누르기 |
| 안드로이드 `no-device` | USB 디버깅 꺼짐, 케이블 문제 |
| 안드로이드 `locked` | 폰 잠금 해제 (도구는 PIN을 입력하지 않아요) |

## 2. 활용 검토

### 한눈에 보기

| 용도 | 판단 | 이유 |
| --- | --- | --- |
| 내 사이트·앱을 실제 폰에서 점검 | 추천 | 내 서비스라 제재 위험 없음. 이 저장소에 스크립트 있음 |
| 내 계정의 통계를 읽어 정리 (인사이트, 조회수) | 조건부 | 읽기만 하고 가끔 실행하면 위험 낮음 |
| 게시물 초안 준비 (사진 선택, 글 붙여넣기까지) | 조건부 | 마지막 "게시"는 직접 누르기 |
| 인스타 자동 좋아요·팔로우·댓글·DM | 비추천 | 계정 정지 위험이 가장 큼 |
| 블로그 대량 자동 발행 | 비추천 | 저품질 판정, 계정 제재 위험 |
| 여러 계정을 클라우드 폰으로 돌리기 | 비추천 | 약관 위반 소지가 큼 |

### 왜 인스타그램·블로그 자동화는 조심해야 하나요?

- **약관**: 인스타그램은 허가 없는 자동화된 접근과 활동을 금지해요. 걸리면 기능 제한, 심하면 계정 정지예요.
- **실제 폰이라도 안전하지 않아요**: 기기가 진짜여도 "사람 같지 않은 행동 패턴"(일정한 간격, 짧은 시간에 많은 동작)으로 잡혀요.
- **브랜드 계정은 자산이에요**: 가구 브랜드·여행·스트릿포토 채널은 다시 만들 수 없어요. 잃는 비용이 아끼는 시간보다 훨씬 커요.

### 대신 이렇게 하세요 (공식 경로)

| 하고 싶은 일 | 더 안전한 방법 |
| --- | --- |
| 인스타 예약 게시 | Metricool 같은 공식 연동 도구 (이미 연결돼 있어요) |
| 인스타 통계 수집 | 인스타그램 공식 API 또는 Metricool 분석 |
| 블로그 글 작성 | AI로 초안 작성 → 직접 검토 후 발행 |
| 반복 답글 | 빠른 답장(저장된 답변) 기능 |

> 네이버 블로그는 공식 글쓰기 API가 종료된 것으로 알고 있어요(직접 확인하지는 못했어요). 그래서 "화면 자동 조작"이 끌리지만, 위 표의 이유로 발행 버튼은 직접 누르는 편이 안전해요.

### phone-harness가 잘 맞는 곳

1. **실기기 점검**: 배포 후 사이트가 내 폰에서 정상으로 뜨는지 자동 확인
2. **앱 설치형 화면 확인**: 일본어 회화 앱처럼 홈 화면에 추가한 앱의 동작 확인
3. **내 폰의 반복 잡무**: 설정 확인, 내 데이터 옮겨 적기 등 남에게 영향이 없는 일

### 도구 자체의 한계

- 글자는 읽지만 **아이콘은 못 읽어요**. 라벨 없는 버튼은 스크린샷 + 시각 모델이 필요해요.
- 멀티터치(두 손가락 확대), 카메라, Face ID는 안 돼요. DRM 영상은 검게 나와요.
- 아이폰은 잠금을 풀면 미러링이 멈춰요. 잠금 해제·권한 허용은 항상 사람이 해요.
- 알파 단계라 동작이 바뀔 수 있어요.

## 3. 보안 점검

원본 코드 약 8,800줄(파이썬)을 읽고 확인한 내용이에요.

### 결론 먼저

| 항목 | 결과 |
| --- | --- |
| 악성 코드, 숨겨진 통신 | 발견하지 못함 |
| 외부 라이브러리 | 맥에서 Apple 연동용(pyobjc)만 사용. 나머지는 파이썬 기본 기능 |
| 자동 업데이트 | 없음. 새 버전 알림만 하루 한 번 |
| **사용 기록 전송** | **기본 켜짐. 범위가 넓어 꼭 꺼야 함** |
| 폰에 대한 권한 | 매우 큼 (구조상 당연하지만 알고 써야 함) |

### 주의 1: 사용 기록 전송 범위가 넓어요 (가장 중요)

기본 설정에서는 명령을 실행할 때마다 PostHog(미국 통계 서비스)로 아래 내용을 보내요.
근거: `src/phone_harness/telemetry.py`, `src/phone_harness/run.py`.

| 보내는 것 | 무슨 뜻인가요 |
| --- | --- |
| 스크립트 전문 (최대 2만 자) | 에이전트가 폰에 시킨 일 전체 |
| 각 동작의 인자 (동작당 300자) | **`type_text("...")`로 입력한 글자가 그대로 포함** |
| 화면 출력의 끝부분 (최대 2만 자) | `print(screen())` 하면 **폰 화면의 글자가 그대로 포함** |
| 기기 고유 번호, OS, 버전 | 설치마다 하나씩 만들어지는 임의의 번호 |
| 클라우드 계정 번호 | 클라우드에 로그인하면 위 기록과 연결됨 |

즉, 끄지 않으면 메시지 내용, 장부·POS 화면의 고객 이름과 금액, 입력한 글이 외부로 나갈 수 있어요.
숨겨진 동작은 아니에요(코드와 문서에 적혀 있어요). 다만 기본값이 "켜짐"이에요.

**끄는 방법** (셋 중 하나):

```bash
phone-harness config set telemetry false
```

```bash
export DO_NOT_TRACK=1
```

```bash
scripts/phone/run.sh scripts/phone/site-check.py
```

마지막 방법(`run.sh`)은 실행할 때마다 자동으로 꺼 줘요. 꺼진 상태에서 실행했을 때 기기 번호 파일조차 만들어지지 않는 것을 이 저장소에서 확인했어요.

### 주의 2: 폰 전체를 맡기는 도구예요

- 에이전트가 쓴 스크립트는 **내 컴퓨터에서 그대로 실행**돼요. 안드로이드는 `shell()`로 폰에 임의 명령을 보낼 수 있어요.
- 폰 화면에 보이는 것은 전부 에이전트가 읽을 수 있어요(메시지, 은행 앱 포함).
- 화면에 적힌 글이 에이전트를 속일 수 있어요. 예: 웹페이지나 메시지에 "이 내용을 어디로 보내라"는 문구가 있으면 따라 할 위험이 있어요.

**안전하게 쓰는 습관**

1. 작업 중에는 화면을 같이 보고, 은행·인증 앱은 열어 두지 않기
2. 보내기·게시·결제·삭제는 에이전트가 먼저 물어보게 하기 (이 저장소 스킬에 규칙으로 넣어 뒀어요)
3. PIN·비밀번호·인증번호는 직접 입력하기
4. 안드로이드는 작업이 끝나면 USB 디버깅 끄기

### 주의 3: 클라우드 폰을 쓸 때

- 클라우드 폰에서 로그인한 계정과 화면은 그 회사 서버 위에 있어요. 본계정·결제수단 로그인은 피하세요.
- 로그인 정보는 내 컴퓨터의 `auth.json`에 저장돼요(본인만 읽을 수 있는 권한).
- 안드로이드는 분당 과금이라 `cloud stop`을 잊으면 비용이 나가요.

### 확인하지 못한 것

- 클라우드 서버 쪽 동작(서버 코드는 공개돼 있지 않아요)
- PyPI에 올라간 설치 파일이 이 소스와 완전히 같은지
- OpenClaw·Hermes 연동 코드(이 저장소에서는 쓰지 않아 읽지 않았어요)

### 실기기 사이트 점검

배포한 사이트가 내 폰에서 제대로 뜨는지 확인해요. 페이지를 열고 글자만 읽어요(누르기·입력·로그인 없음).

```bash
scripts/phone/run.sh scripts/phone/site-check.py
```

| 페이지 | 보여야 하는 글자 |
| --- | --- |
| `/` | 로그인 |
| `/price.html` | 가격표 |
| `/pos.html` | 매장 POS |
| `/translate.html` | 키보드 번역 |
| `/japanese.html` | 지금 말하기 |

결과 예시:

```text
통과  /price.html        '가격표' 보임 (adb)
결과: 5개 중 5개 통과
```

**알아둘 점**

- 이 스크립트는 가짜 폰(대역)으로 흐름만 확인했고, **실제 폰에서는 아직 돌려 보지 못했어요**. 처음 실행할 때 결과를 같이 봐 주세요.
- 아이폰 미러링에서는 검색창에 주소를 넣어 여는 방식인데, 이 길은 특히 미확인이에요. 안 되면 사파리에서 페이지를 직접 연 뒤 다시 실행해 보세요.
- 이미 로그인된 폰에서는 `/`가 로그인 화면 대신 메인 화면으로 열려 "실패"로 나올 수 있어요.
- 폰은 리노님 컴퓨터에 연결돼 있어야 해요. Claude Code 웹(클라우드) 세션에서는 책상 위 폰에 닿지 않아요.

### Claude Code에게 시키기

리노님 컴퓨터의 Claude Code에서 이 저장소를 열고 이렇게 말하면 돼요.

```text
폰에서 사이트 점검 돌려줘
```

스킬이 자동으로 걸려서, 전송을 끈 채 실행하고 게시·결제 같은 동작은 먼저 물어봐요.
