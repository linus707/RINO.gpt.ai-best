## ① 프로필 소개글 + 하이라이트

### 소개글 3안 (인스타 150자 이내)

**A안 — 촬영법 중심 (추천)**
```
도시의 온도를 기록합니다 📷

👇 댓글 키워드 남기면 지도 DM으로 보내드려요
```

**B안 — 여행자 정체성 중심**
```
여행을 영화처럼 기록하는 사람, 리노 🎞
일본 스팟 + 폰으로 찍는 촬영 공식
📩 게시물 댓글 키워드 → 루트 지도 DM
```

**C안 — 짧고 강하게**
```
일본을 영화처럼 찍습니다 📷
스팟 · 촬영공식 · 여행템

```

- 이름 칸(검색에 걸리는 곳): `얼뚱트립 | 일본여행 · 촬영 꿀팁`
- 링크: 인포크/링크트리에 "여행템 · 촬영템 · 스냅 문의" 3개 버튼

## ② 키워드 댓글 → 자동 DM 세팅

### 준비물
- 인스타 계정이 **프로페셔널(크리에이터/비즈니스)** 계정이어야 해요
- 페이스북 페이지 연결 (메타 공식 파트너 툴이 요구하는 경우가 많아요)

### 툴 추천: ManyChat (메타 공식 파트너)
> 요금제·무료 한도는 자주 바뀌니 가입 전에 manychat.com 요금 페이지에서 꼭 확인하세요.

**세팅 순서 (5분)**
1. manychat.com 가입 → Instagram 연결
2. `Automation` → `+ New Automation` → 템플릿 중 **"Auto-DM links from comments"** 선택
3. 트리거: `User comments on your Post or Reel` → **특정 게시물** 선택 (전체 게시물 X)
4. 키워드: `단풍` (+ `紅葉`, `ㄷㅍ`도 추가) — 매칭 방식은 **contains(포함)**
5. 공개 답글(댓글에 자동 답글) 3개 랜덤 설정 → 스팸처럼 안 보이게
6. DM 메시지 작성 (아래 스크립트) → **팔로우 확인 조건** 켜기
7. 부계정으로 테스트 → 5~10초 안에 DM 오는지 확인 → `Set Live`

### #2 오사카 도톤보리 밤 — 기획안
- **훅**: `오사카 밤거리, 폰으로 '영화 스틸컷'처럼 찍으려면?`
- **구성 9장**: 표지(네온 사진) → 공감(찍으면 다 관광 사진) → 핵심(비 온 뒤/블루아워가 정답) → 스팟 3곳 지도(에비스바시·도톤보리 강변·우라난바 골목) → 비포/애프터 → 촬영 공식 3단계(노출 −1 / 바닥 반사 / 셔터 1/30 정지) → 체크리스트 → 감성 컷 → CTA
- **댓글 키워드**: `[오사카]` → 밤 촬영 스팟 지도 + 세팅값
- 발행 전 리서치 필요: 스팟별 혼잡 시간, 우라난바 촬영 매너

### #3 도쿄 겨울 일루미네이션 — 기획안
- **훅**: `도쿄 일루미네이션, 빛을 '동그랗게' 찍는 법`
- **구성 9장**: 표지(보케 컷) → 공감(빛이 다 번져요) → 핵심(빛 보케 원리 한 장) → 스팟 3곳 지도 → 비포/애프터 → 촬영 공식(인물 모드 / 빛을 멀리 / 렌즈 앞 빛 걸치기) → 체크리스트(점등 기간·시간) → 감성 컷 → CTA
- **댓글 키워드**: `[도쿄]` → 일루미네이션 지도 + 점등 시간표
- 발행 전 리서치 필요: **2026 점등 기간·시간** (매년 바뀌어서 확인 필요)

## 확인이 필요한 것
- **계정 아이디**: 스킬에는 `@ellttoong.trips`, 대시보드(index.html)에는 `instagram.com/ellttoong.trip`으로 되어 있어요. 실제 아이디로 슬라이드 9장·DM 문구를 맞춰야 해요.
