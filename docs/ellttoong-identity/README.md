## 1. 레퍼런스 분석 — 이 계정이 잘 되는 이유 7가지

### ① 한 줄로 설명되는 포지션
- 프로필: **"추천 촬영템 · 여행템"** + "알고리즘 이기는 '콘텐츠 레시피'"
- 하이라이트: DJI · 브랜드 협업 · Trip.com · SAMSUNG · 아이폰 꿀팁 → **협찬 포트폴리오를 프로필에서 바로 보여줌**
- 즉, "여행 감성 계정"이 아니라 **"여행 + 촬영법 + 장비" 정보 계정**으로 포지셔닝 → 저장·광고 단가가 높은 구조

### ② 시그니처 컬러 하나로 피드 전체를 묶음
- **형광 라임(연두) 한 가지**만 반복: 헤드라인 2번째 줄, 키워드 형광펜 박스, 칩, 버튼
- 배경은 2가지 모드만 사용
  - **라이트 모드**: 크림 페이퍼(약 `#FBFBEF`) + 먹색 글씨(약 `#1B1A1A`) + 라임 → 정보 캐러셀
  - **다크 모드**: 어두운 사진/검정 + 라임 굵은 헤드라인 → 표지, 촬영 꿀팁
- 그리드를 멀리서 봐도 "아, 그 계정" 하고 알아봄 = **아이덴티티의 핵심**

### ③ 타이포 규칙이 일정함
- 아주 굵은 고딕 2~3줄 헤드라인, **핵심 단어 1개만 형광펜 박스** (`야식`, `스스키노`, `50가지`, `[삿포로]`)
- 헤드라인 바로 아래 **작은 일본어/영어 부제** (`夜食、ラーメン以外なら？`) → 현지 느낌 + 신뢰감
- 감성 콘텐츠(뉴욕 릴스)에서만 레트로 손글씨 폰트를 따로 씀 → 폰트로 "정보 / 감성" 구분

### ④ 슬라이드마다 반복되는 장치 (UI 컴포넌트화)
| 장치 | 역할 |
|---|---|
| 우상단 페이지 번호 `2/11` | 남은 장수를 보여줘서 끝까지 넘기게 함 |
| 하단 `NEXT → 다음 장 예고` | **다음 장을 궁금하게 만들어 체류시간 ↑** |
| 상단 작은 칩 (`사진 꿀팁 PHOTO TIPS`, `갤럭시 꿀팁`) | 시리즈 정체성 |
| 마스킹테이프·손글씨 화살표·사진 위 동그라미 | "직접 다녀온 사람" 느낌 |
| 지도 일러스트, MORNING/DAY/NIGHT 카드, 번호 단계 | 정보가 한눈에 → 저장 이유 |
| ✦ 반짝이 별 | 빈 공간 장식, 통일감 |

### ⑤ 캐러셀 11장 스토리 구조 (삿포로 편)
1. **표지**: 장소 사진 + 손글씨 핀 + `밤새도록 줄 서는 삿포로 오니기리+오뎅집`
2. **상황 공감**: `삿포로의 밤 11시, 라멘 말고 야식 뭐 먹지?`
3. **핵심 사실**: `아침·점심·새벽 '24시간' 열려 있어요` + 시간대 카드
4. **위치**: `숙소 몰린 스스키노 한복판` + 지도 일러스트
5. **경험 포인트**: `주문하면 바로 '쥐어' 줘요`
6. **선택 가이드**: `여기는 밥 간을 골라요` (간장 vs 소금)
7. **재미 요소**: `고르는 재미 50가지` (캐릭터 일러스트)
8. **(오뎅)**
9. **실행 공식**: `실패 없는 주문 공식` ①②③④
10. **체크리스트**: `가기 전에 꼭 알아두기` ☑
11. **CTA**: 프로필 카드 + `댓글로 [삿포로] 남기면 식당 정보+찾아가는 법+메뉴판 번역 보내드려요` + 저장/공유/팔로우 버튼

→ 결과: **댓글 400개** (키워드 댓글 → DM 자동발송 구조)

## 2. 얼뚱트립에 맞게 번역하기

### 그대로 가져올 것 (원리)
- 시그니처 컬러 1개 + 2가지 배경 모드
- 핵심 단어 형광펜 박스 + 외국어 부제
- 페이지 번호 · NEXT 예고 · 시리즈 칩
- 공감 → 사실 → 위치 → 방법 → 체크리스트 → 키워드 CTA 구조
- 팔로우 필수 키워드 DM 퍼널 + 프로필 링크로 수익 연결

### 바꿀 것 (얼뚱트립만의 차별점)
| 레퍼런스 | 얼뚱트립 |
|---|---|
| 형광 라임 (트렌디·정보) | **필름 앰버** — "도시의 온도", 필름 카메라 감성 |
| 장비 중심 정보 계정 | **"영화처럼 찍는 법" 중심** — 스트릿포토 실력이 무기 |
| 여러 나라 | **일본 집중** (기존 성과 상위 대부분이 일본) |
| 일본어 부제는 장식 | 일본어 부제 = 현지 메뉴/간판 읽는 실용 정보로 활용 |

### 한 줄 포지션 (프로필용 제안)
```
도시의 온도를 기록합니다 📷
일본 골목을 영화처럼 찍는 법 · 촬영 스팟 · 여행템
👇 댓글 키워드 → DM으로 지도 보내드려요
```

## 3. 얼뚱트립 비주얼 시스템

### 고정 컬러 (시그니처)
| 토큰 | HEX | 사용처 |
|---|---|---|
| `AMBER` (시그니처) | `#FFB23F` | 형광펜 박스, 헤드라인 강조 단어, 칩, 팔로우 버튼, ✦ |
| `AMBER-DEEP` | `#E8901A` | 라이트 모드 위 작은 글씨(대비 확보용) |
| `PAPER` | `#F6F1E6` | 라이트 모드 배경 (필름 인화지 느낌) |
| `INK` | `#171513` | 헤드라인 / 박스 안 글씨 |
| `SUB` | `#5B554D` | 본문 보조 |
| `NIGHT` | `#121418` | 다크 모드 배경 (CTA, 야경) |

> 레퍼런스 색은 녹화 화면에서 추출한 근사값이고, 앰버는 얼뚱트립용으로 새로 정한 색이에요.
> **기존 스킬 규칙과의 차이**: 지금 `ellttoong-studio` 스킬은 "주제마다 팔레트를 새로 정의"하는 방식인데, 그러면 피드가 매번 달라져서 아이덴티티가 안 쌓여요. → **AMBER·PAPER·INK·NIGHT는 고정**, 주제별 리서치는 `ACCENT2`(보조색) 1개와 사진 보정 톤에만 적용하는 걸 추천해요.

### 타이포
- 헤드라인: **Pretendard Black/ExtraBold**, 2~3줄, 자간 -3%
- 강조: 한 장에 **형광펜 박스 1개만** (2개 이상 쓰면 효과 사라짐)
- 부제: 일본어 한 줄 (Pretendard Medium, 70% 투명도)
- 감성 릴스 커버만 영화 자막 느낌 세리프/손글씨 1종 허용

### 슬라이드 공통 컴포넌트 (1080×1350)
- 우상단 `n/총장수` 알약
- 좌상단 시리즈 칩: `📷 리노's 촬영 공식` / `🗾 로컬 스팟` / `🎒 여행템`
- 하단 좌측 `NEXT → 다음 장 한 줄 예고`
- 하단 우측 `ELLTTOONG TRIP` 또는 `📷 리노's Pick` 서명
- 장식: 마스킹테이프(앰버 80%), ✦, 사진 위 손글씨 동그라미

## 6. 실행 순서 (리노님 할 일)
1. **프로필 정리**: 소개글 3줄 교체 + 하이라이트 커버를 앰버/다크로 통일 (스팟 · 촬영공식 · 여행템 · 협업)
2. **DM 자동화 세팅**: 키워드 댓글 → 자동 DM 툴 연결 (팔로워 조건)
3. **첫 3개 캐러셀**은 이 템플릿 그대로 일본 주제로 발행 → 그리드에 앰버 3장이 나란히 보이게
4. 2주 후 저장·댓글 수를 기존 평균과 비교
5. 결과 좋으면 `ellttoong-studio` 스킬의 팔레트 규칙을 "고정 시그니처" 방식으로 업데이트
