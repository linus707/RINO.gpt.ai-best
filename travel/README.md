# 여행 홈 (travel)

`linuscompany.co.kr/travel/` — 도시를 고르고 숙소 지도로 들어가는 첫 화면이에요.

| 기능 | 설명 |
|---|---|
| 치는 대로 도시가 뜨는 검색창 | 도시 이름·영어·나라·동네(예: 하카타, 콜로세움)로 찾아요. ↑↓ 키로 고르고 Enter. 목록에 없으면 **"지도에서 찾기"**로 숙소 지도의 검색(호텔·동네·장소)으로 넘어가요 |
| 도시 사진 카드 | 도시마다 사진(또는 색 배경), 이번 달 기온, 숙소 지도·숙소 순위·월별 날씨 링크 |
| 이달의 여행지 날씨 | 이번 달/다음 달 평균 최고·최저 기온, 강수량, 옷차림. 카드를 누르면 12개월 표가 나와요 |
| 카드 등장 애니메이션 | 화면에 들어올 때 카드가 살짝 올라와요. 휴대폰의 "동작 줄이기" 설정을 켜 두면 움직이지 않아요 (외부 라이브러리 없이 브라우저 기본 기능) |
| 구글 애드센스 | `config.js`에 게시자 ID를 넣으면 켜져요 (아래 참고) |

## 도시 추가·수정 — `config.js`

```js
{ id: 'osaka', name: '오사카', en: 'Osaka', country: '일본', flag: '🇯🇵',
  map: '/travel-map/?sheet=' + encodeURIComponent('오사카 시트 CSV 주소'),
  photo: 'https://…/osaka.jpg',   // 직접 찍은 사진 추천. 비우면 색 배경
  aliases: ['난바', '우메다'], colors: ['#E0656B', '#F2A07B'] },
```

- `map`이 비어 있으면 카드에 "숙소 지도 준비 중"으로 보여요. 도시별 구글 시트를 만들면 주소를 넣으세요.
- 사진은 **직접 찍었거나 사용 허락을 받은 사진**만 넣어 주세요.

## 날씨 자료 — `data/climate.json`

`scripts/travel-climate.py`가 만들어요. 도시를 추가하면 그 파일의 `SOURCES`에 한 줄 넣고 실행하세요.

```bash
python3 scripts/travel-climate.py
```

| 도시 | 출처 | 기간 |
|---|---|---|
| 후쿠오카·오사카·도쿄 | 일본 기상청(JMA) 공식 평년값 | 1991~2020 |
| 방콕·파리·뉴욕·시드니 | 미국 NOAA NCEI 관측값(GHCN-Daily)으로 계산 | 2015~2024 평균 |
| 다낭·로마 | 두 곳 모두 빠진 날이 많아 **비워 뒀어요** ("날씨 자료 준비 중") | — |

- 날씨는 미리 계산해서 파일로 저장해요. 방문자가 볼 때마다 날씨 서버를 부르지 않아요.
- Open-Meteo 같은 무료 날씨 API는 **광고가 있는 사이트를 상업 이용으로 보고 무료 사용을 막아서** 쓰지 않았어요.
- 화면 아래에 출처를 표시해요. 지우지 마세요(JMA 자료 이용 조건이에요).

## 구글 애드센스 켜기

1. [애드센스](https://adsense.google.com)에 가입하고 `linuscompany.co.kr` 사이트를 등록 → 심사 통과 기다리기 (보통 며칠~몇 주)
2. 승인되면 받은 **게시자 ID**(`ca-pub-숫자16자리`)를 `config.js`의 `adsenseClient`에 넣기 → **자동 광고**가 켜져요
3. 원하는 자리에 광고 단위를 쓰려면 애드센스에서 광고 단위를 만들고 슬롯 번호를 `adsenseSlot`에 넣기 → 도시 카드 아래에 "광고" 칸이 생겨요
4. 저장소 맨 위에 `ads.txt` 파일을 만들고 아래 한 줄을 넣기 (배포할 때 자동으로 사이트 맨 위에 올라가요)
   ```
   google.com, pub-숫자16자리, DIRECT, f08c47fec0942fa0
   ```

- 광고가 켜지면 화면 아래에 "광고와 제휴 링크가 있어요" 안내가 자동으로 나와요.
- 페이지 보안 설정(CSP)에 애드센스 주소를 미리 허용해 뒀어요. 광고가 일부 안 뜨면 브라우저 개발자 도구 콘솔에서 막힌 주소를 확인해 `index.html`의 보안 설정에 추가하세요.
- 유럽 방문자용 쿠키 동의 창은 애드센스의 **개인정보 보호 및 메시지** 메뉴에서 켜면 구글이 알아서 붙여요.
